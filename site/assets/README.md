# 素材：文件名就是接口

页面不写死文件名，`main.js` 按 `data-id` 去这个目录找。**放对名字就出现，没放就还是那块带说明的格。**

| 类型 | 要放的文件 |
|---|---|
| 截图 | `<编号>.webp` |
| 录屏 | `<编号>.webm` + `<编号>.mp4` + `<编号>.webp`（首帧海报，探这张判断整套在不在） |

录制约定（spec §6）：浏览器 1440×900 无书签栏、**产品切深色外观**、演示库、光标隐藏；手机 / 平板用设备模拟到 390×844 / 768×1024；截图 2× 导出后压成 webp。单个文件控制在 3MB 以内（托管方单文件上限 25MiB，但首屏体验按 3MB 算）。
