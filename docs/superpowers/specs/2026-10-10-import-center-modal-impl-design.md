### T2 「这个月有没有」接口（后端）
`GET /api/import-log/coverage?ym=YYYY-MM`，读权限沿用 `/api/import-log/**` → import:view。每类返回一条：

| 类 | 显示 | 判据（和本月出账同口径） | 来源 |
|---|---|---|---|
| ledger、report_is/bs/tb | 公司胶囊 | 复用 `DataHomeService.scheduleSources`（:172，改成包内可见） | 现成 |
| s10 | 期区胶囊 一期…宿舍 | 同上 | 现成 |
| salary | 有 / 没有 | 同上 | 现成 |
| meter | 期区胶囊 | `meter_reading ⋈ meter.zone` 按 zone 计数；全集取 `ZoneService.candidates` | 新 SQL |
| pvMeter、cpMeter | 到 X月X日 | `MAX(read_date)`，不限月（图 B72：选 8 月也写「到 9月30日」） | 新 SQL |
| pv、charging_7/8、elec、elecCost、office_13/14 | 到 N月 | 所选年 `MAX(acct_month)` | 新 SQL |
| pnl_s1..s5 | 到 N月 | `pnl_row` m1..m12 非空的最大月，五张一次 GROUP BY | 新 SQL |
| budget | N年已有 | `budget_row` 该年 `amount_budget IS NOT NULL` 存在 | 新 SQL |
| contractFull、billingTerms | 不按月 | 不查 | — |

- 算缺：胶囊里有 done=false；按月表没有；「到 N月」< 所选月；「到 X月X日」< 所选月最后一天（所选月是本月时比到昨天）；预算该年没有。合同不算缺。
- 同一接口带回每类「上次导入」：时间、谁、行数（合同类单位是「户」）。
- 已知口径差：损益附表「到 N月」看的是格子非空，屏上「填入」派生的值也算（PnlService.java:47）。按「数有没有」这是对的，不改。

**稿上没做 / 和稿不一样的**：
- 台账核对表没做成图上的 5 列（租户 / 上月结余 / 本月应收 / 本月收款 / 本月结余）：应收、结余是后端按结余链推的，前端预览算出来可能和导进去以后不一样，待用户定。现在显示账册里的列。
- 附表10 分段那句没引出认不出的词（图「标题里的「宿舍楼」认不出…」）：解析器只有认出期区才把它当标题，这种段实际不会出现；改写成「没有标题，看不出是哪个期区，选一下」。
- 按年分段（预算、损益附表）核对表没有月份 / 年列：图没画，年跟着文件走、没有地方接改动。
- 后端报的导不了的行写「第 N 条」（发出去的第几条），不是 Excel 第几行；核对页查出的才是 Excel 行号。
- 「粘贴的 N 行」把表头那行也算进去了。
- 充电桩抄表的「去看」一律落到汽车充电桩那一屏的分桩明细（导入记录不记桩型）；年度预算、合同的「去看」不带月份。
