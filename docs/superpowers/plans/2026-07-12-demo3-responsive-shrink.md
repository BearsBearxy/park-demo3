# demo3 窗口缩小响应式方案 spec(2026-07-12)

用户:设计浏览器窗口缩小时的排版方案,参考市面成熟软件,定方案并实现。

## 0. 成熟产品的共识(方案依据)

桌面型后台(Ant Design Pro / GitLab / Grafana / Jira)对窗口缩小的处理是**分级重排,绝不缩放**:
1. **导航先让位**:低于 ~1280px 侧栏自动收起为图标轨(用户仍可手动展开);
2. **栅格降列**:多列卡片网格按断点 3→2→1 列重排;
3. **硬地板**:低于某宽度(常见 960~1024)不再无限挤压——页面出横向滚动,保内容不变形
   (数据密集型工具的诚实做法;表格内部横滚照旧);
4. **不用 transform 缩放**(字号失控、点击目标漂移,反模式);移动端 drawer 对桌面财务工具属 YAGNI。

## 1. 现状资产(不重复建设)

- 已有:分析层 `av2-grid ≤1100px 全堆叠`、主数据 `mx-body ≤1100px 回落`、`av2-kpis auto-fit`、
  工具条 flex-wrap、AnaEChart ResizeObserver 自适应、侧栏手动折叠(ui.sbOpen)。
- 缺口:①侧栏不会自动让位;②1100~1280 中间档 12 列格直接满排(s4 三连挤);③无全局地板,
  <900px 无限变形。

## 2. 方案(三级)

| 档 | 行为 |
|---|---|
| ≥1280px | 现状不动 |
| 1024~1280px | **侧栏自动收起**(图标轨保留;手动展开仍可);分析层 `av2-s4 → span 6`(两列)、`av2-s8 → span 12`(既有 1100 全堆叠断点保留在其下) |
| <1024px | **全局地板 min-width 960px**,应用外层出横向滚动;其下所有既有 ≤1100 断点照常生效 |

## 3. 实现

### T1 侧栏自动折叠(stores/ui.ts)
- `matchMedia('(max-width: 1280px)')`:进入窄档 → `sbOpen=false`;离开窄档 → `sbOpen=true`。
- 窄档内用户手动 toggle 照常生效(保持到下次跨断点);SSR/测试环境无 window 时跳过(guard)。
- 逻辑抽纯函数或直接在 store 内(短小即可);ui store 若有测试则补跨断点用例(jsdom matchMedia mock)。

### T2 分析层中间档(components/ana/ana.css)
```css
@media (max-width:1280px){ .av2-s8 { grid-column:span 12; } .av2-s4 { grid-column:span 6; } }
/* 既有 ≤1100 全堆叠规则保留在其后(层叠顺序:1100 规则须写在 1280 之后或特异性覆盖) */
```
注意与既有 `@media (max-width:1100px)` 的书写顺序,窄者后写。

### T3 全局地板(components/shell/AppShell.vue)
- 应用根 stage `min-width: 960px`;外层滚动容器 `overflow-x:auto`(确认现根节点谁滚动,
  地板挂对元素——页面级横滚出现在 <960px 视口时,≥960 无横滚)。
- 主数据三屏/KPI rail ≤1100 回落等既有规则不动。

## 4. 验收(多宽度矩阵)
浏览器实测 4 档宽度 × 关键屏(cockpit/tenants/ledger 宽表):
- 1440:与现状零差异;无页面横滚
- 1180:侧栏自动收起为图标轨;驾驶舱 s4 卡两列;无页面横滚;手动展开侧栏可用
- 1000:全堆叠布局;无页面横滚
- 900:页面出横向滚动(地板 960 生效),内容不变形
vue-tsc 0 错;vitest 全绿(ui store 若补用例)。
