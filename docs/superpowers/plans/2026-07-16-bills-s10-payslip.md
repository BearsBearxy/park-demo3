# 2026-07-16 账单明细改口径：附表10 工资条式明细 + 一户一文件导出

用户需求（对 2026-07-15 账单页的修订）：
1. 抽屉明细**不按管理公司**分行——台账是「租户交钱的明细」（实收口径）；「每个租户每个月应该交的钱」以**附表10**为准。
2. 工资条式明细：一行=一个租户（根租户一行 + 每个子租户各一行，如 季海莲 / └季海莲宿舍），列=**附表10 的费用列明细**（非只有应收实收总数）。
3. 导出：单户导出按钮放**抽屉内**；外面按钮=批量导出，**一个租户家族一个独立 Excel 文件**（不是一个文件多 worksheet），方便园区逐户发给租户催收。

## Spec

### 后端
- BillController 新增 `GET /api/bills/s10?year&month`：返回该期（acct_month='YYYY-MM'）全部 s10_record 行：tenantId、tenantName、phase、25 费用列（BillS10RowDTO 平铺）。只读、viewer 可用、空期空数组。补最小 IT（有数据期返回行、列值锚点与 s10 屏全等、空期空数组）。
- 既有 `GET /api/bills`（台账口径）**保持不变**——外层列表行/KPI/实收/结余仍是台账事实。

### 前端抽屉（BillsView）
- 保留顶部台账口径 stat（本期应收/实收/期末结余/上期结余）——这是收付事实。
- 「成员明细（按公司分行）」整块替换为**工资条表**：
  - 行 = 家族成员（根在前，子租户 └ 前缀缩进）+ 末行「合计」
  - 列 = 该家族内**非零**的附表10 费用列（列名 import 自 views/sales-income/layout.ts 的 leaves 展平，禁止手抄）+ 行合计列
  - 成员→S10 行匹配：tenantId 优先，tenantName 全等兜底（s10.tenantId 可空）；一成员多条 s10 行（跨 phase/profile）按列求和并一行呈现
  - 无 S10 记录的成员照常出行，值全「—」并加「无附表10记录」小徽标（催收要看得见谁缺数）
  - 列多时表区横向滚动（抽屉宽度不撑爆）
- 抽屉底部动作区新增「导出账单」按钮 → 该家族单个 xlsx 直接下载。

### 导出（billExcel 重做）
- 单户账单条 xlsx（单 sheet）：标题（期间+户名）→ 工资条表（成员行 × 附表10非零列 + 合计行/列）→ 汇总区（台账口径：上期结余/本期实收/期末欠费 + 附表10应收合计）→ 催缴语（BILL_DUE_DAYS 沿用）。文件名 `账单-YYYY年MM月-户名.xlsx`。
- 批量导出（外层两按钮语义不变：欠费户/全部）：**fflate zip 打包**，包内一户一个独立 xlsx（同上版式），zip 名 `账单-YYYY年MM月.zip`。理由：136 户逐个触发下载会被浏览器拦截；zip 解开即一户一文件可逐个发送。XLSX.write(type:'array') → fflate.zipSync。
- 依赖：新增 fflate（^0.8，零依赖 ~8KB）。旧的「一文件多 sheet」逻辑删除；aggregateFamilies（台账族聚合）保留供外层表/KPI。
- spec 更新：工资条 AOA 构建（族列并集非零过滤、成员求和、合计行）+ zip 文件命名。

## 边界
- 附表10 与台账应收存在差异是常态（recon 屏的职责），账单条上两口径并存：明细=附表10，实收/结余=台账。
- s10 行 tenantName 与租户主档不一致时（历史别名）按无记录处理——recon 屏已有名称对齐工单，不在本刀内解。
