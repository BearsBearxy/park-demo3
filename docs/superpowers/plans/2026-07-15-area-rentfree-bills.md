# 2026-07-15 面积模型 + 免租期时间轴 + 账单管理启用

用户决策（已确认）：公摊系数=全园区默认 0.8 换算可改；月租金=租赁面积×单价自动算可手动微调；账单=Excel 一户一张账单条；存量面积暂无数据→**留空不推测**（不用租金反推污染主数据），分析层只算有数据的合同并显示覆盖率。**本版不提交。**

## Spec

### F1 合同面积模型（建筑面积 / 租赁面积 / 单价）
- `contract` 新增列：`building_area DECIMAL(12,2)`（建筑面积㎡）、`unit_price DECIMAL(10,2)`（租金单价 元/㎡/月），均可空（存量留空）。既有 `rent_area` 语义明确为**租赁面积（计租面积）**。
- 换算逻辑（纯前端录入辅助，系数常量唯一定义点）：`RENT_AREA_FACTOR = 0.8`；填建筑面积 → 租赁面积自动 = 建筑面积/0.8（round 2dp，**可改**）；填单价 → 月租金自动 = 租赁面积×单价（round 2dp，**可改**）。手动改过的目标框不再被联动覆盖（脏标记）。
- 新增/编辑弹窗字段顺序：建筑面积 → 租赁面积(自动/可改) → 租金单价 → 月租金(自动/可改)。
- 抽屉展示：建筑面积、租赁面积、单价、实际换算系数=建筑/租赁（有数据才显示）。合同列表「面积㎡」列头改「租赁面积㎡」。
- 校验（后端）：两字段 ≥0 可空；不强制勾稽（现实有特例）。

### F2 免租期（装修期）+ 合同时间轴
- 存储：`contract` 加 `rent_free TEXT` 列，JSON 数组 `[{"start":"2026-01-01","end":"2026-02-15","note":"装修期"}]`。区间模型同时覆盖「装修期 N 天」和「逐年指定月份免租」。
  <!-- ponytail: JSON 列而非子表——纯展示用途；若日后免租参与应收计算再升子表 -->
- 后端校验：合法 JSON 数组、start/end 为 ISO 日期且 start≤end、≤24 段；仅此，不校验是否在合同期内（前端提示）。
- 录入 UI：合同新增/编辑弹窗内「免租期」区块：行式编辑（起、止、备注 + 添加/删除行）；前端校验区间在合同期内（越界给警示不阻断）。
- 时间轴可视化：`views/contracts/FPContractTimeline.vue`（纯 CSS/SVG，不用 ECharts）：横条=合同期（签订→到期），**红色段=免租期**，蓝色段=计租期，今天位置竖线标记；hover 显示区间日期+备注。放在合同抽屉（租赁期间下方）。

### F3 分析层：面积转换率/公摊率
- 落点：分析层「出租与楼栋」ParkView 新增「面积转换」卡片：
  - 各楼栋条形对比：Σ在租合同建筑面积 vs Σ租赁面积（在租=active/expiring）
  - 全园区指标：实际换算系数 = Σ建筑/Σ租赁（对比 0.8 基准线）、平均分摊率 = Σ实际出租建筑面积/Σ楼栋建筑面积
  - **覆盖率护栏**：卡片显著位置显示「N/M 份在租合同有面积数据」，0 数据时整卡空态+引导文案（去合同管理补录）
- 数据源：现有合同 list API 加新字段后前端聚合，不加分析端点。

### F4 账单管理页面启用（bills）
- 导航：`fpNav.ts` bills 占位 → 真实屏 `views/bills/BillsView.vue`；路由接线。
- 后端：新增只读端点 `GET /api/bills?year&month`（BillController）：返回该期**全部公司**的台账行 × 租户(name/parentId/parentName) × 公司名——账单按家族聚合必须跨公司（厂房与宿舍可能在不同公司主体，如季海莲/季海莲宿舍）。行内含 21 费用列 + 应收合计/上期结余/实收/期末结余（复用 LedgerService 既有派生口径，不重算）。GET 端点天然对 viewer 开放。
- 页面（遵循 LIST-PAGE-SPEC）：年/月选择器 + 搜索；KPI 左栏：本期账单家族数、应收合计、实收合计、期末欠费家族数；主表=一行一个**租户家族**（根租户名+成员数徽标，列：本期应收、上期结余、实收、期末结余、成员数），点行展开家族成员明细行（复用 familySort 口径：族键=parentName??自身名）。
- 导出（SheetJS，复用现有 excel 导出模式）：
  - **单户账单条**：一户一张 sheet——表头（园区/期间/户名）、行=费用项目（21 项只列非零 + 小计分组：租金类/物业类/水电类）、列=家族成员+合计、汇总区（上期结余/本期应收/实收/期末欠费）、落款催缴提示语。
  - **批量导出**：全部家族或仅期末欠费>0 的家族，每户一 sheet，文件名 `账单-YYYY年MM月.xlsx`。

## 风险

- 面积全空期分析卡片必须是引导空态而非 0% 假数据。
