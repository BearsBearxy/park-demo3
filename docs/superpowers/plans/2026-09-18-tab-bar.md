## 3. 坑
- 「当前页签」在 `commit()` 时 = 导航**之前**的路由 value；afterEach 里必须先 `commit(to)` 再 `setActive(to)`。调用方的 `open()` 只登记，不动页签条（对抗复查后改，见 §4）。
- 被换下去的屏不 dropState（缓存实例留着，下次点回来还在；LedgerView 那条「别 bump epoch」的约束仍成立）。
- 首页与新标签页不进 `recent`，不能收藏，不能被 ctx 写。
- `NAV_SCOPE_PREFIX` 判「我正在编辑」：握着该屏锁根下任一把锁即算（presence.holdsEditUnder）。
- 旧用户本地存着 `['data-home', …]` + 预览槽：读时首页补在最前、预览槽丢弃。

  2. 浏览器后退到已关掉的屏会把当前页签换掉 → 后退 / 前进开在右边（popstate 标记须在 createRouter 之前注册，浏览器实测坐实）。
  3. 先改页签再导航，取消 / 失败 / 被踢走留下幽灵页签 → 改成「登记 + 导航落定再 commit」。
