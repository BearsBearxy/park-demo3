## §1 三条动线的诊断（代码证据摘要）

### 1.1 财务专员：一个月 ≥15 屏顺序访问，4 屏要主管站在旁边输密码

| 环节 | 现状 | 证据 |

### 1.4 外壳机制（角色无关）

- **两套进入语义**：侧栏/rail/首页/分析深链 = `openFresh`（重置）；页签/面板/最近/期间条 = `open`（恢复）。UI 无任何标识。
- **preview 页签被静默替换**：任意导航顶掉未 pin 的 preview（`tabs.ts:122-125`），`LedgerView.vue:643-647` 注释直接承认「去加个别名就把台账那页顶没了」。
- **分析层 9 处深链全部 `pin:true`**，页签条会被塞满。
- **「当前层」三处答案不一致**（股东深链进不可见层时 rail 无高亮、面板退回分析层、面包屑写「数据中心」）。
- **rail 点当前层也跳走**（`IconRail.vue:36-39` 无 guard）；**logo 不可点**。
- **1366×768 属 XL 档**（BP.l=1280），面板内联，内容区 ≈ 1027px；折叠钮旁边就是死的收藏钮。
- **护栏面**：`fpNav.spec.ts` 钉 4 层/51 项；`palette.spec.ts` 钉「恰好 3 个层组」；8 份视图测试以「侧栏点击 = 全新重建」为前提；`size-check` index 191KB 已三次上调。

## §2 外部调研的收敛结论（≥3 路独立证据）

### 2.1 结构：rail + panel 是对的，尺寸在区间内，问题在**内容**不在**容器**
- 两层（模块切换 + 上下文面板）、面板内 ≤2 级：GitLab super sidebar、Azure 门户菜单+服务菜单、Carbon 48⇄256、M3 rail 3-7 项、ProLayout mix、FineBI/Quick BI 双导航。我们 4 层 rail（有 2 字标签，过 NN/g「不能只有图标」）+ 234 面板，**不动容器**。
- 国内物业同类（快鲸 14-17 顶级组、智轩云 10、泛普一组 18 叶）证明扁平大菜单是用户**忍受**的不是喜欢的；我们的 4 层比它们紧。

### 2.2 长列表：rollup + 仅激活组展开 + 记忆
- Stripe「主 5 + Shortcuts + 分组 + More」、Notion「显示 5 / 全部」、Polaris「仅激活父项展开 + View all」、Azure「组默认折叠、记住、展开全部」、Power BI「sections collapsed by default」。
- 组头永远可见（Baymard）；不要把 4 层塞进一个「菜单」。

### 2.3 常用 + 最近：面板顶部一等区，角色预置比用户自定义重要
- Atlassian Nav 4 把 Recent / Starred 做成顶级；Stripe 把 pinned + recent **合一节**（省高度）；Metabase Bookmarks 在树上方；FineBI 收藏是目录的**平级 tab**；观远 常用 行置顶；金蝶星空 常用功能 **≤7 + 更多**。
- NN/g 内网研究：用户很少自定义 → **角色预置默认**（专员：抄表/公摊/台账…）是主载荷，pin 是加分。GitLab：pin 后原位仍在（不成第二套分类）。Buildium 明确放弃过「第二套分类法」的收藏。

### 2.4 角色：角色 → 容器 + 落地页，不是隐藏叶子
- Salesforce（profile → app + Home）、SAP Fiori（role → space）、Yardi（安全组 → 整套菜单集）、Looker（landing_page 用户属性）、Power BI（audience 落地项）、YonSuite（角色工作台）。
- 三种落地足够：**专员工作台**（本月出账链 + 附表进度 + 我持有的锁）/ **主管看板**（待签发 + 谁在编辑什么 + 6 公司 × 5 步状态）/ **高管驾驶舱**（现有）。系统管理员/只读退回普通层侧栏。
- 股东 = 独立「客户端」（快鲸/金蝶我家云 甲方乙方分端）：只有分析层，rail 可以退成 header 徽记。

### 2.5 月结/出账：一级入口 + 期间矩阵 + 派生状态清单 + 关账只读
- **一级入口**：浪潮云会计（11 项之 7）、账无忧（7 项之 6）、精斗云、好会计「期末」——SME 财务软件无一例外；大 ERP 埋 3-4 层后都补了快捷路径（反例）。
- **形状**：NetSuite Manage Accounting Periods（年>季>月树，每行 5 个锁/关列 + Checklist 图标）+ Period Close Checklist（顺序任务、3 态、padlock 前置未满、Go To Task、Modified By、Notes）；好会计（月格灰显已结 → 「马上检查」→ 红叹号阻断 / 黄叹号可过 → 每条联查 → 零红才出「结账」）；D365 workspace（只看我的 / 全部+按公司，Summary tiles 只显例外）。
- **状态双轴**：工作态（未开始/进行中/已完成，**数据派生**不手工勾）× 约束态（受阻 padlock / 已确认 grey，Aider 三色）。别用 Sage 那种混时间的单枚举。
- **任务行 = 深链**：带期与实体直落工作面，目标屏拥有返回路径（NetSuite「Mark Task Complete」在任务页；QBO Review 打开已按月过滤的报表）。
- **关账后**：清单冻结、目标屏只读（编辑按钮**隐藏**不是禁用）、反结账主管专属 + 理由 + 留痕；跨期规则「N-1 未关不能关 N」（NetSuite/精斗云）。反结账藏修饰键后（精斗云/账无忧/好会计/U8）是公认反模式。
- **前置检查内联**（好业财/金蝶 EAS）：锁账行展开 = 未抄表 N、公摊未平 N、损耗超阈 N、催缴单未生成 N、附表未导入 N、收入核对差异 N，每个数是深链；**计数必须与屏内同源**（否则「假绿」）。

### 2.6 上下文：期间是每屏门 + 横幅，公司是常显 chip，深链进 URL
- 期间不做全局切换器（BC/Intacct/Odoo/Xero/QBO 全部按屏或按报表选）；BC Work Date 横幅「当前期间 ≠ 今天」时常显 + 一键改。
- 公司/实体是常显上下文（Intacct entity selector、账无忧「公司名 + 当前期间 + 红色切换键」、Yardi property selector）。
- 深链一律带 URL 参数：Grafana「Include current time range + variable values」、Power BI drillthrough + 自动 Back 按钮、SAP intent 导航。页签标题带公司与期（BC 2023w2）。

### 2.7 搜索：最近 + 实体 + 动作，限定 3 类实体
- Linear / Vercel / GitLab / Notion / Metabase：面板 = 导航 + 最近 + 动作；BC Tell Me 分节（本页动作 / 页面 / 报表 / 公司数据）；AppFolio Universal Search / MRI GO 把实体搜索当**替代深菜单**的主路径；Xero「/」+ 单字母跳转。
- BC 警告全表搜索慢到要让用户排除表 → 只索引 楼栋 / 租户 / 合同（+ 催缴单号）。

### 2.8 首页：只显例外，不重复菜单
- D365 Summary tiles（逾期/今日/受阻/剩余）、Xero Tasks widget（只标未对账/逾期）、QBO Books review（异常计数即任务）、Odoo journal cards（每日记账一卡：N 待处理 + 主动作 + kebab）、速达 导航图（流程图即首页）。
- 星空默认首页塞满厂商卡片，专门出了「精简版」——首页要 lean。

### 2.9 页签：保留，补三件事
- 国内规范（星空 锁定页签跨登录持久、FineBI 关闭其他/全部、Arco/TDesign 页签栏）；西方产品全靠浏览器页签。
- 补：页签标题含期/公司；溢出折叠下拉（Semi）；固定页签持久到用户级。BC 唯一的差异化「弹出连接窗口做对比」→ 我们的「收入核对 vs 台账」可考虑分屏而非再开页签。

## §3 洞察 → 机会

| # | 洞察 | 机会 | 影响 | 成本 |
|---|---|---|---|---|
| I1 | 专员 15 项按**工序**用，侧栏按**对象**列 | 数据层第一项「本月出账」= 期间矩阵 + 5 步清单（含参数）+ 附表 9 项进度；侧栏 5 屏保留为它的行 | 高 | 中（新屏，零后端：5 个 `/months` 端点已在） |

## §4 任何重设计必须守住的约束（外壳审计 `constraintsAnyRedesignMustKeep`）

1. `fpNav.ts` 是唯一事实源：路由表 / tabs / TabStrip / 链路条 / 命令面板全由它派生。
2. 导航可见性 = `visibleLayers(navLayers, can('system:view'))`；读全开；落地页必须在可见层内。
3. tabs store 三个 localStorage 键格式不变；S 档 tabs 照常运转只是不渲染。
4. KeepAlive key = `value:epoch`，max 10；至少 8 份视图测试 + 3 个 store 建立在「侧栏点击 = 全新重建」之上 —— **改 I3 必须同步改这些测试的口径**。
5. 深链协议：目标屏 setup/onMounted 消费 query；`LedgerView.gotoTenants` 反之必须 `open({pin:true})`。
6. 响应式四档；XL 一像素不动；L/M 浮层 `closeTransient` 不落盘；`ui.ts` 六条测试口径不动。
7. 零布局位移：在场点 / 红点 / 进度条 absolute；手机栏占位壳高度公式。
8. 浮层点外关 capture mousedown；带遮罩 = `--z-modal`；折叠钮排除在点外判定之外。
9. `NAV_SCOPE_PREFIX` 正反向护栏；`scopeNote` 喂锁不喂 seat。
10. index 块 191KB 预算；新增外壳代码要么懒加载要么再签字。
11. BOOK-WORKBENCH §7：按期屏必经显式选期门；实体切换在左栏；出账链期**只记会话内**（用户 2026-08-29 拍板，I2 若要持久化到 sessionStorage/URL 需重新拍板）。
12. DESIGN-FIDELITY §一/§二 像素基准（面板 234 / 行 34 / gap 16·2 / 组标题 6px 12px）。
13. 用户工作节奏（memory）：一次一屏 + 对抗复查；断言逐条破坏验证；计数与屏内同源否则假绿。
