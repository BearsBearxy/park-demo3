# 能源与电费分析层设计（ENERGY-ANALYSIS-SPEC）

2026-07-20 定稿。把四个新数据域（光伏分栋抄表 / 汽车·电动车充电桩分桩明细 / 电费成本模型）接入经营分析层。风格铁律：与既有 15 屏分析一致（AnaEChart 紧凑仪表盘、结论条、深链 openFresh、AnaMethodNote 口径注释、AnaEmpty 空态、覆盖率护栏——数据不足显示引导而非假数字）。

## 1. 新屏「电费成本分析」（value: elec-analysis，能源专题组（2026-09-03 SIDEBAR-UX-REDESIGN §2.3 由「专题分析」拆出））

数据源：elec_cost_entry（含 2025 模拟种子）+ metrics 年度序列 + price_cfg。含 simulated 数据时页头常驻说明条「本页含模拟数据（灰标口径），真实电费单导入后自动替换」。

- **结论条**：年度园区电费收益 / 光伏投资收益 / 基本用电费收益 / 售电协议损益（4 个年累计，人话一句）。
- **图1 · 收益四指标月度趋势**：4 条线（园区电费收益/光伏投资收益/基本电费收益/售电损益），月度。
- **图2 · 总表电费结构**：月度堆叠柱——一期(分时/基本/商业)、二期(分时/基本)、宿舍、运营净额；功率因数奖励与光伏上网收益作负向(抵减)段。
- **图3 · 购售价差**：公告价 vs 执行价双线 + 月损益柱（双轴）。
- 深链：结论条与图点击 → 电费成本总览对应月。

## 2. PvRoiView 扩展（光伏投资回收屏，接入分栋抄表 = 树状图 3-7 项分析）

既有内容（附表6 口径投资回收）原样保留，下方新增「分栋抄表分析」区（数据源 pv_reading/pv_station；无数据整区 AnaEmpty 引导去分栋抄表录入）：

- **发电效率**（第 3+7 项）：效率 = 发电总量 ÷ 装机容量（kWh/kWp，即等效小时）——装机容量每栋不一（光伏板规模不同），效率才是跨栋可比口径。
  - 图A：各站月发电效率柱状对比（覆盖率护栏「N/13 站已录装机容量」，无容量的站不入图并列名）；
  - 图B：效率月度趋势线（按发生日期汇月，全园加权 + 可选单站）。
- **消纳结构**（第 4+5 项）：自消纳 / 上网 / **损耗（=发电总量 − 自消纳 − 上网）** 三段堆叠柱，按站与按月两个视角；损耗率 % 副轴线，损耗为负（计量异常）红点标注。
- **消纳收益**（第 6 项）：各站月消纳收益（Σ自消纳×price_snap）+ 上网收益（上网×0.453 参数价）对比。
- 口径注释：效率分母=站配置装机容量；收益=快照单价口径与抄表屏全等。

## 3. 新屏「充电桩分析」（value: charging-analysis，能源专题组（2026-09-03 SIDEBAR-UX-REDESIGN §2.3 由「专题分析」拆出））

汽车 / 电动车 **双 tab**（Segmented，各自独立视角，默认汽车）。数据源 cp_reading/cp_station/cp_power_usage（无数据 AnaEmpty 引导）。

- **结论条**：本年充电量 / 收益 / 手续费 / 平均损耗率（当前 tab 口径）。
- **图1 · 桩月度量收**：各桩充电量柱 + 收益线（双轴），月度。
- **图2 · 运营商结构**：运营商收益占比环图 + 手续费率（手续费÷(收益+手续费)）对比。
- **图3 · 电表损耗率趋势**：每运营商 损耗率 =（电表量−Σ充电量）÷电表量 月度线；负值红点（计量异常）；无电表月断点不连线。
- 深链：→ 对应屏分桩明细。
