# S14-COEF-BOOK-SPEC — 系数簿：催缴单页批量编辑（管理费单价 + 层份）

> 状态：**草案，版式待用户拍板**（mockup 确认制）。调研依据：wf_ebf3e91d（价目版本语义/成员月行/入口惯例/户级例外盘点，2026-08-10）。

## 1. 需求（用户 2026-08-10）

催缴单页面加一个编辑入口，批量修改所有租户的系数——**只含 用电维护费单价（电力管理费 mgmt_fee）与 层份（车间池成员 weight）**，不含合同签订的部分（租金/容量等一律不进）。版本逻辑与价目管理一致。

## 2. 版本逻辑（对齐价目管理）

价目管理的版本语义（PriceCfgService:112-137）：
- **常数键**：acct_month=YYYY-MM 的行「自该月起生效，直到更晚版本覆盖」（取 acct_month≤ym 最大者，''=初始版）；
- scope 级联 tenant:{id} → zone → ''，首中即返；
- UI=「选定月切面」：切月看当月生效值，编辑列「新价(N月起)」，单格即时写回，清空=删该月版本行。

### 2.1 管理费单价 → 直接复用价目底盘（零后端改动）

mgmt_fee 是白名单常数键、户级可覆盖（overridable），版本前滚已有。批量编辑器 = 对多户循环 PUT /api/price-cfg。
**沿用双键约定**：户级例外必须 mgmt_fee 与 mgmt_fee_commercial 同值成对写（tenant-price-exceptions.sql 惯例，保证引擎走哪支都被压过）。默认 0.16 不落户级行（显示为继承灰体）；录入=写双键；清空=删双键该月版本。

### 2.2 层份 → member 月行升级为「版本组前滚」（一处引擎小改）

底盘已齐（调研结论）：alloc_rule_member 有 acct_month 列 + 唯一键(rule,acct_month,tenant)，API updateRule+memberMonth 可写月行，引擎 pickMembers 消费。数据零 DDL。

**唯一语义缺口**：pickMembers（AllocService:113-116）现为「月行=仅该月生效」（精确匹配），与价目的「自该月起前滚」不同。改为：

```
取 acct_month ≤ ym 的最大版本组（''=初始版最小），整组快照替换。
```

- 现库 247 行全部 acct_month=''（零月行）→ 行为零变化，回归安全；
- 改后：2024-03 版本组自动沿用到 04/05…直到下一版本；重生成历史月取历史版本组——与价目完全同构；
- 版本组=**整名单快照**（改一户即复制全名单为新版本组）：与「历史月已出账口径不动」哲学一致，UI 明示；
- PoolLedgerView「仅本月」checkbox 文案改「自本月起生效」；V69 注释同步修订；
- BillNoticeService:779 applyPackages 的并集过滤改走 pickMembers 同源（顺刀，低风险）；
- AllocMemberDTO 补 acctMonth 或 /rules 走 pickMembers（消除双行平铺歧义）。

## 3. 入口与版式 v2（用户 2026-08-10 二轮反馈定稿方向）

- 入口：BillNoticesView `.bn-actions` 内、「重新生成」左侧；**居中窗口卡片**（编辑池弹窗同款 modal，非全屏、非路由），关闭即回催缴单页。
- 交互 = **选租户 → 选系数 → 改 → 保存**：
  1. 期页签 一期/二期/三期（照抄催缴单 resolvePhase 归期）+ 搜索；
  2. 租户表带**多选框+全选框**（按楼栋分组）；
  3. **系数下拉**（一次编辑一个系数）：电力管理费单价 / 电梯层份 / 消防层份 / 水价 / 装机容量费单价 / 绿化水收取价 / 包干电价 / 公共用电包干额 / 公共用水包干额——即价目「户级例外」全部 overridable 键 + 二期层份；层份仅二期页签开放；
  4. 列：☑ | 租户 | 楼栋 | 当前生效值·生效自（例外徽标）| 新值(生效月起)；
  5. **统一修改=唯一改值入口（v3 定稿，用户 2026-08-10 三轮反馈）**：勾选租户→输入一个值→「应用到选中」写入暂存；**表格无逐行输入框**（不想一个一个点），每户保留"当前生效值·生效自"展示列 + 只读"暂存新值"列（带单行撤销 ×）；
  6. **暂存-提交模型**（非价目的单格即时写回）：所有改动先入本地暂存（徽标+计数），「保存」一次性提交；**退出编辑时若有未保存暂存再提示保存一次**；「应用空值」=删该月版本回退（批量条支持清除模式）。
- 生效月选择器：默认=催缴单页当前 ym；版本语义=自该月起前滚（§2）。

## 3.1 户级例外集成（用户确认：同一功能，并入）

价目页右栏「户级例外」卡与本窗口**读写同一张 tenant_price_cfg、同一版本链**——本窗口即其批量入口。价目页例外卡降级为只读展示+跳转系数簿（删除其 FPDrawer 新增表单，避免双入口漂移）；单价类键（mgmt_fee 双键/water+water_pipe 配套/capacity_fee/green_rate/elec_package/share_*_fixed）在本窗口按既有配套约定成组写。
