## 1. 用户拍板（2026-09-19）

| # | 定了什么 |
|---|---|
| K1 | 方向 A：**整卡浅色底、无边框、右上图标**（参考图 SnowUI 那种） |
| K2 | 配色 = 现稿：列表大卡按位置 `--accent-slate` → `blue` → `sky` → `cyan`；分析屏小卡按位置 `sky` / `slate` 交替 |
| K3 | **分析屏小卡去掉迷你趋势线**，右上角空着、不补图标 |
| K4 | 范围 = KpiCard / AnaKpiTile / FPStat（+ 台账抽屉手抄的一张）+ 算式类（利润公式条、杜邦、收入核对平衡条）；其余手搓的 8 种这次不动（稿 KpiA 第 5 节有归类表） |

## 2. 写字色（浅色底上 ≥4.5:1，令牌已进 tokens.css）

| 用途 | 令牌 |
|---|---|
| 标签、大数 | `--text-primary` |
| 说明小字 | `--text-muted-tint`（`--text-muted` 在 slate 上只有 4.50） |
| 涨 / 跌 | `--delta-up-text` / `--delta-down-text`（成本类反转，沿用 `anaFmt.deltaColor` 的 invert 规则） |
| 警示说明 | `--warn-text` |
| 浅底上的状态蓝 | `--info-text-on-tint` |

## 3. 三个组件

| | 列表大卡 `ds/KpiCard.vue` | 分析屏小卡 `ana/AnaKpiTile.vue` | 抽屉小卡 `fp/FPStat.vue` |
|---|---|---|---|
| 底 / 边 | tint 底、无边、圆角 16、内边距 20、行距 12 | tint 底、无边、圆角 12、内边距 12、行距 4 | 有 tint 用 tint、没有用 `--surface-card`；圆角 16、内边距 12×14、行距 4 |
| 标签 | 14/20 `--text-primary`，右上图标 18（`--text-secondary`） | 12/18 `--text-primary`，右上空着 | 12/18（原 11） |
| 数 | mono 24/30 600，单位 16 sans 500 | mono 20/26 600，单位 14；太长降 16 | mono 20/26 600（原 19，不在字号阶梯上），单位 14 |
| 涨跌 | 数右边同一行，12 号，↗/↘ 图标 + 值 + 灰字「环比」 | 数下面，11/16 mono，**固定两行高 32**；「距目标96%」这类整段一起换行 | 无 |
| 说明行 | 12/18 `--text-muted-tint`，单行省略 | 同涨跌位（灰字 / 警示色） | 11/16 `--text-muted-tint`（原 `--text-disabled` 1.6:1） |
| 高 | 随内容 | **108**；AnaShell `.anx-kpis` 占位最小高 109 → **120** | 随内容 |
| tint 入参 | 保留 `tint`，不传时按位置取 K2 的顺序 | 按在排里的位置 `sky` / `slate` 交替 | 保留 `tint` |

- 删掉：KpiCard 的色点；AnaKpiTile 的 `trend` 趋势线（入参保留为可选、不再画，调用方的 `trend` 一并删掉）。
- 「放不下」按数字位的实际宽度量（连单位；卡片改宽、字体换入都重量），不按字数：先按大号排，溢出就降一档；降了还溢出才省略号 + 悬停看全。插槽里给的数一样量。
- 加载中：盒子不变，只有数字位换成微光条（沿用现有 `.fp-shim`，零位移）。分析屏首进占位瓦（AnaShell `kpiHold`、园区 / 园区能耗屏的占位）就是加载态，不写「—」。
- 台账抽屉手抄的「本月结余」改用 FPStat（正数 `--hue-orange` 照旧（灰底 4.98，稿 KpiA④ 抽屉小卡「本月结余 · 正数」）、负数 `--delta-down-text`、零 `--text-primary`，规则不变）。
- 利润表 / 资产负债表 / 科目余额表的 `.fin-kval` 缩放去掉，走 KpiCard 的 24 / 20。

## 4. 算式类（KpiFormula A 半边）

| | 样子 |
|---|---|
| 利润公式条（FinPnlView `.fin-chain`） | 每个数一格浅底：被加减的数 `slate`，等号右边的结果 `sky`，最后的净利润 `blue`；运算符 − = → 在格与格之间；数字 20、标签 12、百分比 11。一排放不下时右边那句注（营业外占利润总额 …）挪到下一行靠右 |
| 杜邦（FinBalanceView） | ROE 大格 `--accent-blue`、数 28；三个因子各一格浅底（sky / slate / cyan）、数 20；运算符 = × 20 灰 |
| 收入核对平衡条（ReconWorkbench `.rc-balance`） | `--accent-blue` 底；已配平字 `--info-text-on-tint`（原 `--hue-blue` 4.23:1）；有差额 `--warn-bg` 底 + `--hue-orange` 字；缺记 `--danger-bg` 底 + `--delta-down-text` 字 |
