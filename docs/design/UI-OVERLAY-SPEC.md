# UI-OVERLAY-SPEC — 浮层必须点外面就关

> 定稿 2026-08-15。需求来源：用户报障「修复所有页面里面，所有卡片，所有编辑模式下的
> popover 下拉条，点开了点击别的区域不会回弹关闭的问题，完全反用户使用习惯」。

## 0. 一句话

**任何浮层（下拉、popover、菜单、选择器面板），点它外面就必须关。**
这是三十年桌面/网页的肌肉记忆，不关＝坏了。

---

## 1. 铁律一：点外关闭必须挂 capture 阶段

```ts
document.addEventListener('mousedown', onDoc, true)   // ← 第三参 true 不能省
```

**为什么**：宿主容器普遍带 `@mousedown.stop`。本仓库最典型的是 `FPDrawer.vue:33`：

```html
<div class="fp-dwr" @mousedown.stop>   <!-- 挡住 backdrop 的关闭 -->
```

冒泡阶段的 `document` 监听在这个容器**内部永远收不到事件** ——
于是抽屉里每一个下拉，点外面都不关，只能再点一次触发器或按 Esc。
capture 阶段先于任何 `.stop` 派发，不受影响。

同样带 `.stop` 的还有表格行（`@click.stop` 防止行点击冒泡开抽屉）、卡片、勾选列，
所以**不在弹窗里的浮层也一律挂 capture**，别赌宿主没有 `.stop`。

用 `mousedown` 而不是 `click`：`click` 要等 mouseup，拖选文本、快速连点时行为不稳。

## 2. 铁律二：Esc 只关自己，必须 stopPropagation

```ts
function onKey(e: KeyboardEvent) {
  if (e.key === 'Escape') { e.stopPropagation(); setOpen(false) }
}
```

**为什么**：宿主弹窗自己也监听 `window keydown` 的 Esc 来关闭。不阻断的话，
用户想收起一个下拉，结果**整个抽屉一起关掉**，录到一半的表单全丢。

## 3. 铁律三：浮层自身要清理监听

`onUnmounted` / 关闭时 `removeEventListener`，且 **capture 标志必须与注册时一致**
（`removeEventListener(type, fn)` 不带 `true` 移不掉 capture 监听，会泄漏）。

## 3.5 什么不算浮层（别照字面扩大化）

本规范只管**浮在内容之上、遮挡下方**的定位元素 —— CSS 上有 `position:absolute/fixed` +
`z-index`（通常还有 `box-shadow`）。判据不是「有个 ref(false) 控制开合」。

**不适用**：内联折叠区 / 手风琴 / 「展开·收起」区块。它们在正常文档流里，
展开只是把后面的内容往下顶，不遮挡任何东西。给它们加点外关闭是**把好控件改坏**：

> 实例（2026-08-15 扫全站时判定保留）：`PoolLedgerView.vue` 池配置抽屉②段的
> 「从其他位置添加表」`.pl-otherbox` —— 无 position/z-index/shadow，是 `border-top` 虚线分隔的
> 流式折叠区。若按本规范挂 capture 监听，用户在②段搜到表勾选后、转头去改③段基数或点页脚保存，
> 搜索面板连同 40 条候选**当场收起**，必须重新展开重搜。折叠控件在桌面与网页惯例里
> 从不因点外部而收起。同类还有各屏告警清单的「展开/收起」、`LossLedgerView` 的 `cfgOpen`。

一句话判据：**它盖住别的东西吗？盖住＝浮层，顶开＝折叠区。**

**另一个例外**：必须处理的居中弹窗（编辑权被接管、别的标签页退出或换了账号）点外面不关、`Esc` 也不关，只能点它自己的按钮 —— 这时页面已经不能用，关掉只会留下一页发不出请求的界面（2026-10-01 补，已实现（2026-10-01，jfen/hint-impl），画布 06-E）。

**第三个例外：导入中的导入弹窗**（2026-10-03 补，画布 11 节 ImportBusyClose，细则见 §8）：点了「导入」、请求还没回来的那段时间，× 不响应（悬停说明「导入完成前不能关闭」）、遮罩和 `Esc` 不关、遮罩盖住页签条（切不了页签），关浏览器标签走浏览器自己的确认（§7 02-D）；屏自己收写浮层的两条路（编辑态转假、页签停用）也不收它（§8 规矩 4）。导完（成功或失败）一切照常。

## 5. 新写浮层的自查

1. 有没有 `document.addEventListener('mousedown', ..., **true**)`？
2. Esc 有没有 `stopPropagation()`？
3. 注销时 capture 标志一致吗？
4. **能不能不自己写** —— 优先用 `ds/Popover.vue` 包一层，别再复制第七份。

## 6. 不做

不引入全局浮层管理器/焦点陷阱（focus trap）。当前浮层都是轻量下拉，
一个 capture 监听足够；真出现嵌套浮层的层级冲突再议。

## 7. 不用浏览器自带弹框 —— 已实现（2026-10-01，jfen/hint-impl；2026-09-30 定稿，画布 02-A / 02-B / 02-C / 02-D）

> 2026-09-30 用户拍板。图在 `../../../运维文档/设计稿/未实现/提示层级与公共电核算-2026-09-29/`
> （线上画布 https://claude.ai/artifact/6EeNrVfvacktpfgMsrbw4F ）第 02 节，标准件见 06-B 第 8、9 件。
> 盘点时站内有 219 处浏览器自带弹框（confirm 62 · alert 157）。
> `LAYOUT-STABILITY-SPEC` §4.1 从「提示放哪一级」的角度写了同一套，两边说的是同一件事。

**站内不再调用 `window.confirm()` / `window.alert()`**，换成软件里自己的两件：

| 原来 | 换成 | 规矩 |
|---|---|---|
| `confirm()` | 确认弹窗（02-B） | 居中，440 宽。标题是问句或后果，正文给数，主按钮写动作本身（「删除 76 条」，不写「确定」）。删除类默认焦点在「取消」 |
| `alert()` 报动作成没成 | 结果回执（02-C） | 底部居中，最多叠 3 条。成功 4 秒自己收；失败不自己收，带「重试」 |
| `alert()` 报表单字段填错 | 字段下面的报错 | 不走回执，贴在那个字段下面 |

**离开确认（02-A）**：应用内离开 —— 关页签、切账期、退出登录 —— 都走同一个离开确认
（稿上画的是关页签：标题「关闭「园区抄表 · 2023-08」？」，正文「这页有 3 处改动还没保存。」，按钮「继续编辑」「放弃改动并关闭」）。
**0 处改动时不弹**，直接关、直接放锁。侧栏跳转不弹：正在编辑的屏点侧栏会开新页签、不卸载，改动不会丢（`TAB-BAR-SPEC` §2 例外二；2026-10-01 改，原来侧栏跳转也列在这里）。编辑态这边的细则见 `EDIT-MODE-SPEC` §6。

**关浏览器 / 刷新（02-D）是唯一例外**：网页只能用浏览器自己那个框，样式和文字都改不了。
所以只在**真有未保存改动**时才挂；没有改动不拦（编辑锁已挂在 `pagehide` 上释放，不靠这道框）。

## 8. 导入弹窗：点「导入」之后 —— 已实现（2026-10-03，jfen/elev-reports-params-import；画布 11 节 ImportSeg / ImportOne / ImportDone / ImportFail / ImportBusyClose）

> 2026-10-03 用户：「按照现在设计稿，规范按你决定」。以前点「导入」弹窗当场关掉、各屏自己发请求、再另弹一层结果，
> 写的那段时间屏上什么都没有。

**2026-10-10 改稿（0.34.0，图 md-v2-*）**：导入弹窗是居中的 **720 × 700 固定窗**（短屏按 `min(…, 100%)` 收，≤600 全屏），每一步一样高，换步窗口不跳；顶上三步条「选数据 / 核对 / 导入」；**主按钮只在底栏一处**。各步画什么、核对页四种见 IMPORT-GUIDE §二「三步与核对页」。

**弹窗不关，内容区原地换卡**：核对页 → 进度卡 → 结果卡（成功）或失败卡。按钮都在弹窗底栏。

| 卡 | 画什么 | 脚部 |
|---|---|---|
| 进度卡 · 逐段（附表10，每段一次请求） | 「正在导入 K 段 · N 行」+ 右上「已用 m:ss」；**真进度条**（按已写完的段累计发出的行数，每段走 200ms）；「已写进 a / N 行」（a = 写完那些段后端回的写入数，被跳过的行不算，跑完和结果卡的「导进去」对得上）；每段一行（✓ 已导进去 / 转圈 正在写 / · 没开始）；没有步骤表 | 只一颗灰「导入中…」；× 灰 |
| 进度卡 · 单次请求 | 「正在导入 N 行」+ 副标题；右上「已用 m:ss」；**不确定进度条**（一截横移，不写百分比；系统开了减少动态时原地呼吸，不横移）；「这一步一次写完，中途没有进度可看」；步骤表（沿用 10-02 版） | 同上 |
| 结果卡 | 「✓ 导进去 N 行」（单位随 registry：行 / 家 / 户 / 块表；勾一笔画出 320ms）；右上「用时 m:ss」，刷新没成写「本页没刷新上」；后端报的没导的行写「第 N 条」（发出去的第几条），核对页导不了的写「第 N 行」（文件里的第几行）。三种长相：**平铺**两块数（导进去 / 没导）+ 没导的行逐条列出（核对页导不了的 + 后端报的，不折叠）+ 一句怎么补；**多段**都导进去「N 段」「M 行导进去」+「一期、二期、三期都在库里了。」；**台账**都导进去只一句「9月水电的台账已经在库里了。」。多段、台账有没导的照平铺。抄表的匹配分档、档案改动、「n 条提示」照旧 | 「完成」；从导入中心打开的多一颗「去 X 看」（X = 导进去的那一屏） |
| 失败卡 · 逐段断在网络或 5xx | 「第 k 段（期区）没导进去」+ 原因块 + 每段一行（✓ 已导进去 / ⊗ 没导 / · 没开始）+「一期、二期已经在库里了；接着导只从三期开始，不会重复。」。**断在请求发出后没有回应**时第 k 段写没写进去不知道：标题「第 k 段（期区）没等到服务器的结果」，句子多一句「三期写没写进去，以本页刷新后看到的为准」，段列表那一格写「没等到结果」。进度条先变红 200ms 再换失败卡 | 「关闭」/「从第 k 段接着导」（只重发第 k 段起，前面不重发） |
| 失败卡 · 4xx 整单拒（审核闸等） | 「导入失败，这次一行都没写进去」+ 原因块 +「本期还是导入前的数据。」；有东西留下时多一句（如「新建的 N 家公司已留下」）。**一次导入发多次请求的**（工资逐月、水电逐年、台账整册逐公司）后面那次被拒时前面的已经进库：标题「导入没做完，前面已写入 a 行」，句子「已写入的留在库里，出错那一次和后面的都没写。」 | 「关闭」/「返回修改」（回到核对页，勾选与年月不丢） |

规矩：

1. **200ms 内跑完不出进度卡**，直接出结果卡 —— 一闪而过的卡比不出更吵。
2. **只有逐段才给「接着导」**，且只在网络断或 5xx 时给：后端每段「清本槽导入行再插」且整段一个事务，重发同一段结果相同（`S10ImportApiIT` 重导用例）。4xx 是这份数据本身过不去，重发没用，只给「返回修改」。逐段里第 k 段吃了 4xx，照实写前面已写入几段，也只给「返回修改」。断在第 k 段时前面的段已经进库，本页在出失败卡之前照实刷新一次。
3. **单次请求没等到回应**（断网、超时）：标题写「导入失败，没等到服务器的结果」，下一句「这次写没写进去，以本页刷新后看到的为准。」—— 不说「一条都没写进去」，因为不知道。
4. **导入中关不掉**（§3.5 第三个例外）：×、遮罩、`Esc` 都不响应，× 悬停说明「导入完成前不能关闭」；遮罩在 `--z-modal-2`，盖住页签条；`Ctrl+K` 命令面板在遮罩下面，导入中也不让开（开了能跳页）；`beforeunload` 只在导入中挂，导完就摘。
   屏自己收写浮层的两条路也不收在跑的导入窗：编辑态转假（被接管、授权到期）与页签停用（浏览器后退）时先看 `importBusy`（`importRun.ts`），在跑就留着 —— 收了写入照样跑完，只是人看不到写进去多少、断在哪。导完由人点「完成 / 关闭」；失锁之后再点导入或「接着导」，由各屏 runner 的写口自守挡（返回 `null`，弹窗回到选文件那一屏）。页签停用时导入窗随页藏起，回到页签结果卡还在；藏着的那个不截别处的 `Ctrl+K`。逐段导入每段发之前再问一次还能不能写：失锁了剩下的段不再发（后端写口不校验锁），失败卡写「第 k 段没导进去」、原因「已退出编辑，从这一段起没有再发」，只给「返回修改」。
   锁按月的屏（附表10、附表12）导完要跳到第一段的年月：跳期放到点「完成」关窗之后 —— 一换期编辑态就退出，放在导入里跳会把人踢出编辑。
   防连点：主按钮连点两下只跑一次。台账的月份、会盖掉几家在进核对页时就查好（registry `precheck`），开跑前不再弹确认框。
5. **失败只在失败卡里说一遍**：不走底部回执，http 拦截器的全局网络报错也不出（0.34.0 起导入写口都带 `silentNetError`，`api/index.ts`）。原因写在失败卡的原因块里，就在用户眼前。
6. 关弹窗瞬间，不淡出；换步旧内容瞬间没、新内容淡入 120ms（`fp-fade-in`，不滑动）。导入中心、月度台账、园区抄表在点「完成」关窗那一刻给导进去的行挂 `fp-row-flash`（浅蓝底 2s 褪，减少动态效果时照留）。

接线（`components/import/importRun.ts` 头注释是协议全文）：`FpImportModal` 给了 `runner` 才走这一路（全仓 17 处导入入口都给了；不给仍 emit 只是兼容，新屏别走）；`segmented` 开逐段；`describe` 改进度卡的数、单位与步骤（科目余额表「6,907 格」）；`go` / `done-note` 管结果卡底栏的「去 X 看」和右上那句。`sub` / `rules` / `sample` / `unit`（台账另有 `precheck`）由 registry 的 `parserProps(key, ctx)` 一起带上，屏上别再自己传 `sub`；`retarget` 给了才在台账「导到 … 改」条上出「改」。`confirm` 已删（0.34.0）。
