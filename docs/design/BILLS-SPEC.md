# 账单管理规范（BILLS-SPEC）

2026-07-16 定稿。账单管理屏（/bills）的业务口径与版式铁律，布局另遵 LIST-PAGE-SPEC。

## 1. 定位与口径铁律

- 账单管理 = **应收账单工具**：数据源 = 附表10（每个租户每月应该交的钱）。
- **实收/结余 = 台账的职责**：本屏不展示实收、不展示期末结余、不提供「确认收款」操作——收款事实在月度台账维护。
- **户数 = 租户家族成员数（主租户 + 子租户，来自租户主数据的 parentId 关系），与租户向几个管理公司交钱无关。** 台账按管理公司记账是「交钱明细」的组织方式，不是租户结构；碧沃丰家族 = 碧沃丰 + 碧沃丰(股份) = 2 户，无论它向几个公司主体交钱。

## 2. 家族与成员构建

- 家族 = 租户主数据的 root + children（不是台账行、不是附表10 行）。
- 抽屉与导出中：**主租户一条明细、每个子租户各一条明细**（合起来 = 该租户租不同场地的收款明细）；**没有附表10 数据的成员也必须出现**，标「无附表10记录」——催收方要看得见谁缺数。
- 附表10 行 → 成员匹配：tenantId 优先，tenantName 全等兜底；一成员多行（跨期数/profile）按费用项求和。
- 匹配不到任何租户档案的附表10 行：按 tenantName 独立成户列出，标「未关联租户档案」——本期应收必须 100% 覆盖附表10，不许静默丢行。

## 3. 页面版式

- **进入流程（期间门）**：进入页面必须先选期间——年 → 月（复用报表屏「年份门+月历」门控流组件与样式，仅可选有附表10 数据的月份），选定后才进入列表；**禁止跳过选择直接落到某个默认月的列表**。进入列表后工具栏保留年月切换；同会话内切页签回来保持已选期间（KeepAlive）。
- **无 KPI 卡片栏**；标题副行直接显示「YYYY年MM月 · 本期应收合计 ¥X · N 户账单」。
- 列表行 = 一个租户家族：户名（+成员数徽标）、本期应收（附表10 合计）、成员构成预览。
- **列宽铁律**：户名/本期应收列显式定宽，成员构成列弹性吸收全部余宽（紧跟应收列，不留无用空隙）；`table-layout: fixed`——列位置不得因内容长短或翻页变化。
- 无 KPI 栏时主列全宽，卡片定高 flex 链不变（LIST-PAGE-SPEC §3）。

## 4. 明细版式（工资条，抽屉与导出同构）

- **行 = 附表10 费用项**（家族内非零项，中文名单一事实源 = sales-income/layout.ts leaves），
  **列 = 成员**（主租户列在前，└子租户列随后）+ 「合计」列；末行 = 各列合计。
- 竖排费用项从根本上消除横向滚动（成员列通常 ≤4，表格自然适宽）；成员多到放不下时才允许横向滚动兜底。
- 禁止转置成「成员行 × 费用列」的宽表（2026-07-16 曾如此实现，13+ 列横向滚动被用户否决）。
- **工资条列宽铁律（2026-07-18）**：`table-layout:fixed`——费用项列 140px 且 **sticky 左固定**（横向滚动时不跟动）；每个成员列 128px 定宽；**合计列为唯一弹性列吸收余宽**（下限 128px，与列表页"唯一弹性列"同律）。**卡片恒占满抽屉内容宽与内容高**——不随费用项/成员多少收缩：宽度满抽屉内容区；高度至少撑满抽屉内容区（容器 flex 链兜底，行少的家族卡片不塌缩），行多时自然增高随抽屉滚动。单费用项、单成员的家族与满表家族卡片同尺寸同观感。成员多到定宽合计超出容器（≥4 成员）时整表取 min-width=定宽总和并在卡内横向滚动。合计列不加竖线分隔。
- **「无附表10记录」提示不得放进列头**（会撑宽成员列）：列头只放成员名（└ 前缀），无记录成员名置灰；提示集中为表格下方一行备注「无附表10记录：成员A、成员B」。

## 5. 收款公司指引（2026-07-18 新增）

- 园区要求租户把不同费用类目转账到不同管理公司（如：租金→创显；维护费/物业费/电梯费/基本用电→按楼栋归属的物业公司；电费水费→一泽/创显）。
- 存储：独立映射表 `bill_pay_company`（tenant_id × fee_key(附表10 colId) → company_id）。**该映射与台账记账公司、楼栋期数完全不联动**——它是"要求租户转到哪"的指引，不是记账事实；公司候选 = 公司主数据全量列表。
- **默认值推导（一次性种子）**：按现有真实数据——每租户×每台账费用列，取该租户该列历史金额绝对值合计最大的记账公司作为默认收款公司，经 台账列→附表10列 映射写入（该列映射须复用/收敛为单一事实源，禁止另抄）。仅存在于附表10 而台账无对应列的类目不种默认（显示「未设置」待用户手选）。后续新租户/细化调整全部由用户手动修改。
- 抽屉展示与编辑：工资条每个**非零金额单元格**下方显示该成员该类目的收款公司短名徽标；admin 点徽标弹 popover（公司列表单选）即改，写入即存（PUT upsert）；viewer 只读。未设置显示灰色「未设置」；未关联租户档案的独立户（tenantId 空）不可设置。
- 导出必须携带指引：xlsx 与打印账单上，每个成员金额列旁配「转入公司」列；账单底部不再只有催缴语，同时注明「请按各费用项目指定公司转账」。

## 6. 导出

- 单户：抽屉内「导出账单」→ `账单-YYYY年MM月-户名.xlsx`（单 sheet：标题 → 工资条表（每成员金额列旁配「转入公司」列）→ 应收合计 → 转账指引说明 + 催缴语；**不含台账实收/结余**）。
- 单户打印/PDF：抽屉内「打印账单」→ A4 打印版式页（浏览器打印/另存 PDF），版式与 xlsx 同构、含转入公司指引。纯 HTML+print CSS，不引 PDF 库。
- 批量：外层单个「批量导出」按钮 → zip 内一户一个独立 xlsx（方便逐户发送催收）。无欠费过滤——欠费口径属台账/催缴清单，不在本屏。
