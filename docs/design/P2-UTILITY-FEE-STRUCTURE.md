## 2. 户内账单组成（厂房，全部数值验证）

```
① 装机容量费(基本用电费) = 合同装机容量 kVA × 22.6 元/月
   · 55 户单价统一 22.6(口述"23"证伪);与用电量无关(氙明 0 度仍收 1582)
   · 非"仅大工业":25kVA 张文峰、7.5kVA 应塘都收;kVA=0 仅威玛斯/陈书谨(钢构)/火炬园
   · 月中起租按天折算(欧伟杰 565×22/31=400.97)
   · power_type 实际语义 = 两部制(有容量费)/单一制(无),不是单价档差异
② 四时段电费 = Σ 时段用量×时段价(尖按峰价);用量=(本月−上月)×倍率
   · 光伏户(永龙)反向有功 4 行按同时段正向价计费,计入电费合计
③ 电力管理费 = 总用量 × 0.16
④ 电梯用电 = 楼栋每层基数 × 户占层数
   · 基数 = [楼栋电梯表 Σ时段量×(时段价+0.16)] ÷ 已出租电梯层数 —— 月度派生值,7 档:
     一145.37(÷5.8)/二169.26(÷6)/三171.58(÷4)/四286.59(÷4.5,广联专用482.12)/五217.33(÷5.7)/六132.77(÷6)
   · 首层户 0 层;力灏 1-3 层按 2 层收电梯、3 层收消防
   · 小数层=同层多户拆分,三种口径并存:面积比(六车间3F 0.29/0.42/0.28)、均分(6F 各0.33)、手工(五车间6F 合计1.11>1)
⑤ 消防用电 = (楼栋消防每层基数 + 0.015×户面积÷户层数) × 户层数
   · 楼栋基数=[消防表计费额(扣广告字寄生表)]÷全楼层数:一20.18/二31.82/三28.10/四32.80/五43.60/六80.28
   · 0.015 元/㎡ = 园区级「生活水泵+消防控制室」表(2163.85 元)分摊标准
⑥ 线路损耗 = (②+④+⑤) × 楼栋损耗率     ← 基数不含①③,宿舍段不计入
   · 拆单户(一泽/帮管好)基数含③:(②+③+④+⑤)
   · 率=[调整度数−(分表合计−总表)]÷总表+0.002,按楼栋 4 档:一0.0271/二三四0.0255(共池,铝缆)/五0.0287/六0.0381
   · 「调整度数」为手工数(一300/二-2500/五1000/六300)
⑦ 路灯公摊 = 租赁面积 × 0.005 元/㎡(池=保安亭路灯表)
⑧ 水费 = 吨 × 3.95(例外:南一/朱漫钳 4.45)
⑨ 水管网维护费 = 吨 × 0.5
⑩ 绿化水公摊 = 面积 × 0.008(五六车间) / 0.01(一至四车间+帮管好维护单)
```

## 8.5 公共电核算表公式审计定稿(2026-07-27) —— §2 公摊单价推导的更正

「公共电数据」20 池逐格验算 100% 吻合，全量公式见 **POOL-FORMULA-AUDIT-2024-02.md**。对本文 §2 的更正与精化：
1. **园区消防 0.015 是两段拼成**：ROUND(消防池2163.85÷148918.01,2)[=0.01] + 六车间广告字档 ROUND(800度÷148918.01,3)[=0.005]，非一次除出；
2. **绿化水乙轨 0.008 = 0.001+0.007**：ROUND(绿化水泵104.46÷148918.01,3) + 五车间广告字档；**甲轨 0.01 = 2023 隐藏表「公共电分摊」M109 化石常数**，仍被广联/罗立剑/嘉荣等活引用（两轨差25%，纠偏候选）；
3. 路灯 0.005 = ROUND(保安亭池685.09÷148918.01,3)；**148918.01=二期园区总面积基数**（硬编码10格）；
4. 车间消防/电梯每层基数 = 池金额÷已出租企业层数（7/5.8/6/4/4.5/5.7/6.5，逐月随出租变动）；
5. 折入规则=叠单价档并从源表剔度数（不并金额）；折入档分子用度数而非金额（量纲混用，本月 ROUND 后无差，换月可能出差异）；
6. 消防水稳压泵 3.23 名义"折入消防电"实际蒸发只挂亏；火炬园广告字 670.06 度从五车间电梯平段冲减、单独向火炬园收；充电桩 2152.4 度不分摊全额挂亏（-1717.05，当月整体亏 -1934.69 主因）；
7. 广联分摊 482.12 = 四车间电梯全层价 382.12 + 100 元手工加价（普通户按层价×3/4=286.59）；六车间广告字"本月行至"为硬造数（=上月+整800度，按定额计）。

## 9. 对派生引擎的结构性结论

1. **月度公摊池是一等公民**:电梯/消防每层基数、损耗率都是「当月公共表实耗 ÷ 分摊系数」的派生值,逐月变动,
   **不能当合同常数存**——引擎要先算池(公共表抄表→池金额→每层基数),再算户。demo3 的 meter ownership
   (share/infra) + P-B alloc 引擎正是这层的家底。
2. 合同侧只需存**静态签约要素**:kVA、计费类别(两部制/单一制)、租赁面积、占用楼层及同层拆分系数、宿舍间清单。
3. 价目侧按月存:四时段价+居民价+管理费率+容量费单价+水价+各公摊单价(0.005/0.008/0.01/0.015/0.06/0.02/0.5),
   支持户级覆盖(0.15/0.10/4.45)。
4. 账单按费项拆收款主体(4 公司),入 bill_notice 时每行带 pay_company。
5. 尖峰按峰价收是政策开关(比率 0%),留参数不删行。
