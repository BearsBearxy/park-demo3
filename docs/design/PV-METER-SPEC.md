# 光伏分栋抄表规范（PV-METER-SPEC）

2026-07-18 定稿。用户确认决策：每栋一个综合消纳单价（收益=自消纳×单价自动算）；抄表按日期记条自动汇月（日抄月抄都容纳）；电站按思维导图种 13 个（C、D座算一个）。**现有附表6 月度汇总功能保持原样不动。**

## 1. 数据模型

### pv_station 电站（楼栋）
- `id、name(唯一)、phase(1/2/3)、capacity_kwp DECIMAL(10,2) NULL 装机容量、price_yuan DECIMAL(8,4) NULL 消纳综合单价(元/kWh)、sort、时间戳`
- 种子 13 站：一期 B座 / C、D座 / E座 / F座 / G座；二期 8栋~13栋；三期 创业大厦 / 工业大厦。
- 装机容量与单价"相对固定、可调整"——站级配置，界面行内可编辑（admin）。电站支持增删（有抄表记录的站删除 409 守卫）。

### pv_reading 抄表记录
- `id、station_id FK(级联删站守卫,不级联删记录——由 409 挡)、read_date DATE、gen_total 发电总量、self_use 自消纳电量、grid_feed 上网电量(均 DECIMAL(12,2) ≥0)、price_snap DECIMAL(8,4) 单价快照、note、source(manual/import)、时间戳`
- **唯一键 (station_id, read_date)**：同站同日一条——日抄天然唯一，月抄用当月任意日期（建议月末）；重复导入幂等 upsert。
- **发电月份 = read_date 派生（YYYY-MM）**，不另存字段。
- **收益口径**：`price_snap` 在录入/导入时快照当时站单价；月度消纳收益 = Σ(self_use × price_snap)。之后调站单价只影响新记录，历史收益稳定不漂移。
- 校验：三量 ≥0 硬校验；自消纳+上网 > 发电总量 前端黄警示**不阻断**（抄表现实有损耗差）。

## 2. 页面流

- 进入 /pv-income 先过**功能门**（卡片样式与账单期间门/SchedYearGate 同款）：
  - 「附表6 · 月度汇总」→ 原 PvView 流程原样
  - 「分栋抄表明细」→ PvMeterView（新）
  - 会话内记住选择（KeepAlive），刷新重进重选。
- **PvMeterView**（遵 LIST-PAGE-SPEC 布局精神）：
  - 期数 tabs（全部/一期/二期/三期，FPPhaseTabs tabs prop）+ 年月选择 + 导入/模板下载/导出按钮。年份选项**数据驱动**（2026-07-19 P0 修复）：有记录年份 ∪ 当前年，升序；初始年 = 最新有数据年（无数据 = 当前年）。
  - 主表一行一电站（定宽列律）：电站名(行内可编辑，重名 409) | 装机容量(行内可编辑) | 消纳单价(行内可编辑) | 本月发电总量 | 自消纳 | 上网 | 消纳收益 | 抄表条数。月度量=该站该月记录求和。
  - 点行开抽屉（fixedHeight）：该站该月逐条抄表记录，行式增删改（日期+三量+备注），收益列=self_use×price_snap 只读展示。
  - 新增电站轻量弹窗（名称/期数/容量/单价）；无数据月空态引导（去导入或抽屉手录）。
  - viewer 全只读。

## 3. Excel 导入（模板本规范定）

- 单 sheet 长表，表头（含别名兼容）：`期数 | 楼栋 | 日期 | 发电总量(kWh) | 自消纳电量(kWh) | 上网电量(kWh) | 备注`
  - 日期接受 YYYY-MM-DD / Excel 日期序列；楼栋按电站名精确匹配（未知站名=行级错误,不整批拦截）；期数列仅校验参考可空。
- 幂等：`(电站,日期)` upsert——重导修正即覆盖。
- 注册进 importRegistry（导入中心+屏内双入口，沿用既有导入闭环：解析→预览→确认→入库→import_log→逐行错误）。
- 「下载模板」前端现场生成 xlsx，含表头+两行示例数据。
- **导出双 sheet**（2026-07-19 P0 修复，错价修正回路）：「YYYY年M月」月度汇总（一行一电站含合计）+「明细」（导入模板七列，一行一抄表记录，站序→日期升序）——导出文件可**直接重导**，重导即按当前站价重新快照。改站单价保存后界面提示该修正路径（历史记录按录入时快照不漂移）。

## 4. 边界与不做（YAGNI）

- 与附表6 的勾稽/自动回填**本刀不做**——数据积累后单独做对账刀（口径：抄表月汇总 ⇄ 附表6 发电收入）。
- 尖峰平谷分时四段价不做（站级单价字段将来可平滑升级为多段）。
- 图表分析不做（分析层 PvRoiView 已有，数据齐后自然接入）。
