## 2. 横切问题（按影响面排）

1. **未闭月污染**（6 屏：驾驶舱、利润表、损益附表、盈亏、预算、费用）。2025-12 附表未录全 → 收入 −64 万。应在 anaData 层判定「未闭月」（收入 ≤ 0 或覆盖科目 < 阈值），趋势图画成斜纹空心柱 + ⚠，轴量程排除，合计/KPI 标「截至 11 月」。
2. **分类色**（8 屏）。期区、收入板块、费用组各定一套固定顺序的类目色（见设计稿 System 板，验证器全绿）：`#378ADD` 蓝 / `#EF9F27` 琥珀 / `#5DCAA5` 青 / `#DB2777` 玫红 / 其他 `#9AA1AB`。蓝族渐变只给有序量。HTML 端分析层的 orange 改用与 canvas 同值 `#EF9F27`。
3. **文字减法**（19 屏）。脚注 → 卡头 ⓘ 弹层（复用 AnaMethodNote S 档实现）；hint ≤ 24 字，交互提示改成 ↗ 图标 + title；ak-head 大页头撤掉，屏名进工具条（驾驶舱/财务 3 屏已是）。
4. **表格与清单**（7 屏）。≤ 10 行 + 「查看全部 N →」深链；默认「只看有值」；≤ 6 列；空态整卡 → 32px 行内条。
5. **数值失真门**（3 屏）。比率 > 300% 或分母 < 数量级 5% → 显示「—」+「基数过小」徽章 + 原值。
6. **局部修正 8 处**（见设计稿 Details 板）：光伏回收标签、驾驶舱目标标签、流失散点轴、桑基标签、期区环→条、充电 2 片环→指标卡、收缴率 15 行→点线、租户趋势→指数。
