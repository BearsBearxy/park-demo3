# 页签栏与顶栏规范（TAB-BAR-SPEC）

> 设计稿：`../运维文档/设计稿/已实现/页签栏与顶栏-2026-09-18/`（线上画布 https://claude.ai/artifact/XR5Lt4gMMeL3gs5kgrQxTd ，v2）。
> **图是规格，本文是它的文字版；两者不一致以图为准。**
> 取代：`docs/superpowers/specs/2026-09-03-sidebar-ux-redesign-design.md` §4.3 的「预览槽 / 深链 pin 规则」与 §6 的「☆ = 固定预览页签」；
> `landingPath` 的「按角色落地」改成「第一次登录时收藏里预置的那一格」（§5.3）。

用户原话（2026-09-18）：tab 的使用逻辑和 Chrome 一致（可随意拖动、添加）；tab 字体不能斜体；☆ 等图标说清功能；在线人数显示大一点、头像看不清；「数据中心 / 本月出账」点前一段能回数据中心；新标签页改为登录后的默认首页。

---

## 1. 页签模型

| 项 | 规则 |
|---|---|
| 一个页签 = 一屏 | 页签按屏（路由 value）记。**同一屏只开一份**：筛选、展开、滚动位置都在那一份 KeepAlive 实例里。要开的屏已经开着 → 直接切过去 |
| 首页 | value `home`，路由 `/home`。永远是第 1 格、固定、只显示房子图标；**关不掉、拖不动、不能取消固定** |
| 新标签页 | value `newtab`，路由 `/newtab`，内容与首页相同（§5）。**同时最多一个**：已经有了再点 + 就切过去（稿没画这一点，是实现上的取舍：新标签页没有自己的状态，开两个没有用处；Chrome 允许多个） |
| 固定（Chrome 的 pin） | 右键「固定」：挪到固定区（首页之后），只显示图标，宽 44，没有 ×。「取消固定」挪回普通区最前面 |
| 顺序 | 固定区在前、普通区在后；各区内部顺序由用户拖动决定 |
| 最近关闭 | 内存里记最近关掉的 10 个（不落盘），供「重新打开关闭的页签」与 ⌄ 列表 |
| 持久化 | **按人分开存**：`fp-app-tabs:<用户名>`（value 数组，含顺序）+ `fp-app-pinned:<用户名>`（固定的 value 数组）+ `fp-app-recent:<用户名>`。没登录不存。浏览器另一个标签页里被顶下线的旧身份，写的是他自己的键，串不到这个人的页签上。改版前不分人的旧键读一次当成这个人的、读完删掉；旧键 `fp-app-preview` 读时删掉 |
| 每次登录 | 页签只剩首页；最近访问、最近关闭、ctx 清空（epoch 不清：它只是缓存 key 的命名空间，清零会让登出那一拍前台那屏重挂一遍）。**同一个人过期后重新登录也清**（登录时清掉这个人存的页签，`auth.loginSeq` +1）；登出同样清掉这个人存的 |
| 页面缓存 | KeepAlive **不设上限**：缓存里只有开着的页签 —— 关掉的、被换下去的屏当场卸载（按纪元剔除）。同一屏只开一份，所以最多就是全站的屏数。设上限会按「最久没看」挤掉页签，连正在编辑的也挤（取代侧栏重设计 D9 的 16） |

## 2. 点哪开在哪

「当前页签」= 路由当前所在的那一格。

| 操作 | 结果 |
|---|---|
| 登录后 | 落到 `/home`（有 `?redirect=` 时照旧去 redirect）；页签只有首页 |
| 刷新浏览器 | 页签、顺序、固定都在；**刷新不算重新登录，不跳回首页** |
| 点左边导航 / 命令面板选一页 / 图标轨换层 / 面包屑第一段 | **在当前页签打开**：当前页签换成这一页，位置不变；被换下去的屏当场卸载，和关掉一样 |
| ↑ 例外一：当前页签是**首页** | 开在**新页签**（最右边）并跳过去 —— 首页不会被换掉 |
| ↑ 例外二：当前页签的屏**我正在编辑** | 开在**新页签**（最右边）并跳过去 —— 不换掉正在编辑的页面。「正在编辑」= 全站编辑态登记表 `auth.editors` 里有登记在这一屏的：握着编辑锁的（台账、三大报表、账册模板、附表页头、出账链各屏…，在锁那一层统一登记）、各屏的编辑模式、系数簿 / 收款簿 / 公司账簿窗口、角色管理有没保存的改动、新建 / 编辑合同弹窗填过东西。登记带屏名，只算这一屏（改前按锁根判：收款簿不握锁认不出，出账链三屏共用一把锁互相误判） |
| Ctrl + 点 / 中键点 左边导航 | 在新页签打开，放最右边，**不跳过去** |
| 右键左边导航 | 菜单：在新页签中打开（Ctrl + 点）/ 收藏此页（取消收藏） |
| 页面里的链接跳到别的屏（驾驶舱点租户、本月出账点一行、报表中心点一张表…） | 在新页签打开，**紧挨当前页签右边**，并跳过去。目标屏一般换全新实例（openDeep 的 epoch++）；台账 / 附表10 去租户管理、导入中心「去查看」、到期墙点合同这几处保住目标屏的缓存实例（`open(v, { pin: true })`） |
| ↑ 例外：铃铛抽屉里的「去本月出账」 | 外壳上的入口，和命令面板一样在当前页签打开 |
| ↑ 例外：同一条出账工序链上的步骤条（`FPStepStrip`） | 在当前页签里走 —— 一步一个页签会把页签条铺满 |
| 点 + | 新建「新标签页」放最右边并跳过去（已有就切过去） |
| 在新标签页上点任何一页 | 这个页签变成那一页（等同「在当前页签打开」） |
| 在首页上点任何一页 | 开在新页签（例外一） |
| 点页签 | 切过去（恢复缓存） |
| 中键点页签 | 关掉 |
| 双击页签 | 没有作用 |
| 关页签 | 关掉的若是当前页签，跳到右边那格，没有就左边那格；弃掉它的缓存（`dropState`，沿用） |
| 关到只剩首页 | 就回到首页（首页关不掉，所以永远至少有一格） |
| 浏览器后退 / 前进 | 目标屏还开着 → 切过去；已经关掉了 → 开在右边的新页签（不把正看着的那一格换掉） |
| 页面内容区里点出来、代码没说开在哪的跳转（裸 push、RouterLink、空态「去录入」…） | 按「页面里的链接」开在右边 |
| 关掉 / 重新加载 / 关闭其他 / 关闭右侧 碰到**我正在编辑**的页签 | 先问一句「「月度台账」正在编辑。关掉会丢失未保存的改动，继续？」；说不就什么都不动 |
| 深链 / 换层 / Shift + 点 到**我正在编辑**的屏 | 只切过去，不换新实例（没保存的改动不被冲掉） |

**时序**：页签条只在**导航落定后**才动（router.afterEach）。点了之后导航被取消、页面文件加载失败、被权限守卫踢回首页，页签条一格不动 —— 不留从没打开过的页签，也不把来源页签换没。

**关掉的、换下去的页签当场卸载**：关掉 / 重新加载一个页签，或它被「在当前页签打开」换下去，它的页面实例立刻卸载（App.vue 的 KeepAlive 按纪元剔除），编辑锁随之释放。正在编辑的屏不会被换下去（例外二），所以不会因此丢改动。

**手机（S 档，没有页签条）**：看不见页签条，也没法关页签，所以打开任何一页（包括回首页）都只留「首页 + 固定的 + 正在编辑的 + 这一页」，其余的当场卸载 —— 手机上点回去、后退回去都是重新打开。页面里的链接、后退到关掉的屏也一样，不往右插。换到电脑宽度看到的就是这几格。

## 3. 页签条

### 3.1 形状与尺寸
- 条高 44，底色 `--surface-sunken`，左右内边距 8。页签高 36，贴底。
- **当前页签**：白底（`--surface-white`），上圆角 10，底边两侧各一个 10px 的外翻圆角，和下面白色顶栏连成一块；字 `--text-primary`、`--fw-medium`。
- **其他页签**：透明底，字 `--text-secondary`；鼠标停着：内缩 3px 的 `rgba(28,28,28,.06)` 圆角底。
- 相邻两个普通页签之间一条 1×16 的竖线（`--ink-100`）；挨着当前页签或悬停页签的两侧不画。
- 页签内：图标 14（非当前 `--text-muted`）+ 标题 12px + 右侧 × 钮 20×20（圆角 6）。
- **标题一律不用斜体**。标题内容照旧：`屏名 · 期 · 公司`（有几段写几段）。
- 首页 / 固定页签：宽 44，只有图标 16，没有 ×。
- + 钮 28×28 紧跟最后一个页签；⌄ 钮在最右，页签滚动溢出时旁边显示总数（等宽数字）。

### 3.2 宽度
- 普通页签宽 = `clamp(96, 可用宽 ÷ 普通页签数, 220)`；可用宽 = 条宽 − 内边距 − 固定页签 − + 钮 − ⌄ 钮。
- 宽度**只跟页签个数有关**，和标题长短无关；标题变了（换期、换公司）不挪位置。
- 窄于 96 就不再缩，页签区左右滚动（隐藏滚动条），切换时把当前页签滚进视野，右缘一道 40px 渐隐。
- × 显隐：页签宽 ≥ 120 时每个页签都显示；窄于 120 时只有当前页签和鼠标停着的那个显示。触屏（`hover: none`）一律常显（沿用 RESPONSIVE-LAYOUT §6.1）。
- **连着关**：用鼠标点 × / 中键关掉一个后，其余页签**先保持原宽**（鼠标下面正好是下一个 ×），鼠标离开页签条后再一起重算宽度。

### 3.3 悬停卡片
鼠标在页签上停 600ms，下方出卡片（宽 280，白底，圆角 12，`--shadow-pop`）：第一行屏名 14 粗；第二行 `期 · 公司`（没有就不出）12 灰；分隔线下一行「层图标 + 层名 · 分组名」12。首页 / 新标签页只出屏名。按下鼠标、开始拖动、打开菜单时立即收起。

### 3.4 右键菜单（页签）
宽 248，行高 34，字 14，右侧灰字提示 12：
1. 在右侧新建页签
2. 重新加载 · 回到刚打开的样子（= 该屏 epoch++，当前页签原地重挂载）
3. 固定 / 取消固定
4. 收藏此页 / 取消收藏
5. —— 分隔线
6. 关闭 · 中键
7. 关闭其他页签（不关固定的）
8. 关闭右侧页签（不关固定的）
9. —— 分隔线
10. 重新打开关闭的页签（没有可重开的时灰掉）

首页上：只有 1、2、10 可用，其余灰掉；新标签页上：3、4 灰掉。

### 3.5 全部页签（⌄）
下拉宽 340，贴右：顶部输入框「搜索已打开的页签」（按标题过滤）；「已打开 · N」列表：图标 + 屏名 + 右侧灰字期间，当前那行 `--accent-slate` 底，悬停出 ×；「最近关闭」最多 5 行，点了重新打开。Esc / 点外关。

## 4. 拖动
- 按住页签横向移动超过 4px 开始拖：被拖的页签跟手、白底浮起一层阴影（`0 6px 18px rgba(28,28,28,.18)`）；它越过邻居一半时，邻居滑进空位（120ms）；松手落进空位（120ms）。
- 只在页签条里左右拖；首页拖不动，别的页签也拖不到它前面；固定页签只在固定区里换，普通页签只在普通区里换。
- 拖到页签条上下方 40px 以外松手：放回原位。
- 拖完那一下不算点击。
- 不做：拖出页签变成新浏览器窗口（§9）。

## 5. 首页 / 新标签页
### 5.1 版式（桌面）
居中一列，顶部留白 64：标志 36 + 「灵睿」20 粗 + 「LinkSight」16 灰；搜索框 600×48 胶囊（点了打开命令面板，右侧 `Ctrl K`）；「收藏」区宽 760，6 列格子（格高 104，圆角 16，`--surface-card` 底，44 圆形白底图标 + 12 字）；「最近打开」两列行（行高 44：30 方块图标 + 14 屏名 + 右侧 12 灰层名）。
### 5.2 收藏
- 在任意屏点顶栏 ☆ / 页签右键 / 左边导航右键加进来；再点取消。在首页格子上悬停出 ×，点了去掉。
- 最多 12 个（两行）；满了再点 ☆ 提示「最多收藏 12 个，先在首页去掉几个」，不加（稿没画这条提示）。按收藏先后排，格子可以拖着换顺序。
- 按账号记：`fp-favs:<账号>`。只能收藏导航里的屏（首页、新标签页不行）。
- 区标题右侧灰字：`N 个 · 在页面上点 ☆ 加进来`。
- 一个都没有时：一块虚线框「还没有收藏。在任意页面点顶栏页面名后面的 ☆，就会出现在这里」。
### 5.3 第一次登录
这个账号从没存过收藏（键不存在）时，预置一格 = 原来按角色落地的那一屏（`landingPath`：录入和审核的人 → 本月出账；零 :edit 的总经理、股东 → 经营驾驶舱；只管账号的管理员 → 用户管理）。区标题右侧灰字改为「先放好了你最常用的一屏 · 在页面上点 ☆ 加更多」（收藏只有这一格且从未改动过时）。
### 5.4 最近打开
就是 `tabs.recent`（最多 8 个，不含首页与新标签页）；为空时整块不出。
### 5.5 首页与新标签页的区别
内容一样；首页上点任何一页开在新页签（§2 例外一），新标签页上点了这个页签就变成那一页。
### 5.6 顶栏
面包屑只写「首页」或「新标签页」；不出期间 chip，不出 ☆。
### 5.7 手机（稿没画，按现有 S 档规则）
单列：搜索框占满宽，收藏 3 列，最近打开 1 列。手机上没有页签条，点任何一页都走 S 档现有导航。

## 6. 顶栏
### 6.1 从左到右
收起导航 · 面包屑 · 期间 chip · ☆ ‥‥‥ 在线的人 · 搜索 · 操作记录（有 system:view 才有）· 版本更新 · 待我处理。☆ 从最左边挪到期间 chip 后面。
### 6.2 面包屑
- 第一段 = 这一屏所在层的名字。当前屏**不是**这一层第一屏时能点：字 `--text-secondary`，鼠标停着出浅灰底（`--bg-hover`，圆角 6）+ 下划线 + 说明气泡「回到 数据中心 · 本月出账」；点了当前页签回到这一层第一屏（数据中心 → 本月出账，账簿与报表 → 报表中心，经营分析 → 经营驾驶舱，系统管理 → 用户管理）。
- 已经在第一屏上：只是标签，`--text-muted`，没有悬停反应。
- M 档（≤960）面包屑只留屏名，沿用。
### 6.3 ☆ 收藏
- 空心 = 没收藏；实心蓝（`--hue-blue`）= 已收藏。
- 点了收藏：☆ 下方出深色条「已收藏，在「首页」上能找到　[撤销]」，4 秒后自己收起，点撤销取消收藏。
- 已收藏时悬停气泡「取消收藏」，点了直接取消（不出提示条）。
### 6.4 图标说明气泡
- 鼠标停 500ms 出，下方深色小气泡（`rgb(40,52,66)` 底、白字 12、圆角 6、带小三角），第一行名字（粗），有快捷键写在右边（灰、等宽 11）；第二行灰字说点了会怎样。刚收起一个又停到旁边的图标上时立即出。按下鼠标即收。
- 文案：

| 图标 | 第一行 | 第二行 |
|---|---|---|
| 收起导航 | 收起导航 | 左边的导航收起来，表格能多看几列 |
| 面包屑第一段 | 回到 数据中心 · 本月出账 | — |
| 期间 chip | 这一页现在看的是哪一期、哪家公司 | — |
| ☆（没收藏） | 收藏此页 | 收藏后在「首页」上一点就到 |
| ☆（已收藏） | 取消收藏 | — |
| 在线的人（人数字样） | 现在谁在线 | 橙圈的人正在编辑 |
| 搜索 | 搜索页面　Ctrl K | 输入页面名直接跳过去 |
| 操作记录 | 操作记录 | 谁在什么时候改了什么 |
| 版本更新 | 版本更新　v{版本} | 这一版改了什么 |
| 待我处理 | 待我处理 · N 件（没有待办时只写「待我处理」） | 等我批的授权、等我审的表、被退回的表 |
| + | 新建页签 | — |
| ⌄ | 全部页签 | — |
| 左下角 ⌘ | 搜索页面　Ctrl K | 和顶栏的搜索框是同一个 |

## 7. 在线的人
- 头像 30、**不叠在一起**（间距 3）、白色 2px 描边；最多 4 个 + 「+N」圆（30，`--surface-sunken` 底，等宽 11）；右侧「**N** 人在线」14（N 等宽粗）。N **包括自己**，和名单人数一致；头像里不放自己。只有自己时写「只有你在线」（灰）。
- 头像里的字：名字两个字写全名，三个字以上写后两个字（欧阳明 → 阳明），字号 11。颜色沿用按账号 hash。
- 橙色外圈 = 正在编辑；半透明 = 快掉线（超过 30 秒没心跳）。沿用。
- 整组定宽 256（按满员算），高 40，圆角胶囊，悬停 `--bg-hover`。人数变化不挪顶栏。
- 鼠标停在一个头像上：气泡「名字　正在编辑 · mm:ss」或「名字　浏览中 / 刚离开」，第二行他所在的屏。
- 点开名单：宽 340；头部「**在线 N 人** · 其中 M 人在编辑」（14 / 12）；每行头像 34 + 名字 14（自己带黑底「你」，别人有角色带描边角色名）+ 所在屏 12 灰 + 右侧状态 12（编辑 mm:ss 橙粗 / 浏览中 / 刚离开）。
- 窄于 1280（L 档以下）：收成胶囊「人形图标 **N** 人」，高 34，点开同样是名单。
- 左下角账号头像同样写两个字（稿上画的是「周明」）。其他地方的头像（租户、楼栋、合同的首字头像）不动。

## 8. 动效
| 什么 | 怎么动 | 时长 |
|---|---|---|
| 切换页签 | 底色瞬间换，不做任何移动 | 0 |
| 新建页签 | 宽度从 0 长到位，右边的 + 跟着让开 | 120ms `--ease-out` |
| 关闭页签 | 宽度收回 0；其余页签等鼠标离开页签条再一起变宽 | 120ms |
| 拖动 | 被拖的跟手；越过邻居一半，邻居滑进空位 | 邻居 120ms |
| 松手 | 落进空位，阴影消失 | 120ms |
| 悬停卡片、右键菜单、全部页签下拉、收藏提示条 | fp-pop-in（下方 4px 淡入） | 120ms |
| 图标说明气泡 | 停 0.5 秒后出；已出过一个时移到旁边立即出 | 120ms |
| 减少动态效果 | 以上全部瞬间到位 | — |

（收藏提示条这一项稿上的动效表没列，沿用全站贴附浮层的规则补上。）

## 9. 不做
- 页签拖出来变成新的浏览器窗口 —— 网页做不到拖回去合并。
- Ctrl + T / Ctrl + W 等快捷键 —— 浏览器自己占着，网页收不到。
- 同一屏开两个页签。
- 多个新标签页（稿没画，见 §1：最多一个）。
- Chrome 的彩色页签分组。
- 手机上的页签条（S 档没有页签条，不变）；手机抽屉里的「回首页」入口（稿没画）。
