# 充电桩分桩明细规范（CP-METER-SPEC）

2026-07-18 定稿。用户确认四决策：附表7 汽车与附表8 电动车**两屏都加、共享桩库**（桩带类型字段，各屏只显自己类型）；充电量/手续费/收益**全手填**（从平台对账单抄，不做自动换算）；电表用电量按**运营商×月一条**，损耗自动派生；万城万种一个同名桩占位。**现有附表7/8 月度汇总功能保持原样。** 编辑模式遵 EDIT-MODE-SPEC。

## 1. 数据模型

### cp_station 充电桩（站）
- `id、name(唯一)、operator 运营商(自由文本：万城万/小桔/…)、vehicle_type('car'|'ebike')、sort、时间戳`
- 种子（V38+V41 修正）：car=小桔/快充1、小桔/慢充1、万城万/万城万；ebike=叮叮充/叮叮充、电信/电信。归属如与实际不符用户在编辑模式改。
- 桩支持增删改（名称/运营商/类型；新增默认当前屏类型）；删有记录桩 409。

### cp_reading 充电记录
- `id、station_id FK、read_date DATE、charge_kwh 充电量、fee 手续费、revenue 收益(三者 DECIMAL(12,2) ≥0 全手填)、note、source、时间戳`
- **唯一键 (station_id, read_date)**：日记条自动汇月（同光伏抄表口径）；重复导入幂等 upsert。

### cp_power_usage 充电桩电表用电量
- `id、operator、vehicle_type、period DATE(取每月1日)、meter_kwh DECIMAL(12,2)、note、时间戳`；**uk(operator, vehicle_type, period)**
- **用电损耗 = meter_kwh − Σ该运营商该类型桩当月充电量**（读时派生不落库）；损耗为负（电表<充电量）黄警示不阻断。

## 2. 页面流

- ChargingView（附表7/8 共享组件）加功能门（同光伏）：「月度汇总（原功能）」/「分桩充电明细（新）」，文案随屏（汽车/电动车）；原流程零改动；会话内记住选择，刷新重选。
- **CpMeterView**（共享，按路由类型过滤桩）：
  - 运营商 tabs（全部 + 桩库 operator 去重动态生成，FPPhaseTabs :tabs）+ 年月 Select（年份选项数据驱动，同光伏：有记录年份 ∪ 当前年，初始=最新有数据年，2026-07-19 P0 修复）+ 工具栏（模板下载/导出常驻；导入/新增桩=编辑模式）。
  - 主表一行一桩（定宽列律）：桩名 | 运营商 | 本月充电量 | 手续费 | 收益 | 记录条数；桩名/运营商在编辑模式下可改（行内或弹窗）。
  - 主表下「电表与损耗」小节：每运营商一行——电表用电量（**编辑模式下录入/修改**，2026-07-18 用户修订）| Σ充电量 | 损耗（派生，负值黄警示）。
  - 点桩行开抽屉（fixedHeight）：该桩该月记录行式增删改（日期/充电量/手续费/收益/备注），浏览态 admin 可用。
  - viewer 全只读；空态引导同光伏。

## 3. Excel 导入（模板本规范定）

- 单 sheet 长表：`运营商 | 桩名 | 日期 | 充电量(kWh) | 手续费(元) | 收益(元) | 备注`；桩名精确匹配（未知桩=行级错误）；运营商列仅参考校验；日期兼容 YYYY-MM-DD/Excel 序列；(桩,日) upsert 幂等。
- 电表用电量**不进导入模板**（每运营商每月一条，页面手录成本更低）。
- 注册 importRegistry（key='cpMeter'），模板现场生成含示例行；导入入口受编辑模式管（EDIT-MODE-SPEC）。

## 4. 不做（YAGNI）

- 与附表7/8 月度汇总的勾稽（数据齐后单独对账刀）。
- 收益自动换算（用户确认全手填）。
- 快慢充费率区分、分时段统计。
