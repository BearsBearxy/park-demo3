# 园区抄表规范（METER-SPEC）

2026-07-21 定稿。P-A 刀：把「全园区租户/公共水电表的花名册 + 月度抄表」从手工 Excel（202405水电表数据表.xlsx 六 sheet 及水电费工作簿内同构 sheet）搬进系统。**只做表档案与读数**；公摊分摊、损耗收取、户级账单是后续 P-B/P-C，本刀不做。

来源文件形态（真实样本 2025全年发生额、预算对比/2024年/）：
- 6 张 sheet = 3 分区 × 2 类：一期园区电/水、二期园区电/水、宿舍电/水；
- 标题行含月份（如「2024年5月二期园区电表抄表记录」）；电表为双行表头（上月行至/本月行至下分 总/尖/峰/平/谷），水表单行表头；
- 首列为表的唯一标识名（如「一车间总电」「金纳D301电」）；倍率=表面走 1 度实算 N 度；
- 已知脏数据：缺本月读数（手工表算出负用量）、幽灵行列（声称 1048576 行/16384 列）、右侧游离备注列——解析必须只取映射列、按标识列裁行。

## 1. 数据模型

### meter 表档案
- `id、kind VARCHAR(8)(elec/water)、zone VARCHAR(8)(p1/p2/dorm)、name VARCHAR(64)(首列标识)、area(区域)、spot(位置)、tenant_name(企业名称,原样字符串——租户档案匹配是 P-B/P-C 的事,本刀不建 FK)、meter_type(表类:总电表/公共用电已分摊/户内用电等,原样)、sub_name(电表①等)、code(表编码)、factor DECIMAL(10,2) NOT NULL DEFAULT 1(倍率)、sort_no、时间戳`
- **唯一键 (kind, zone, name)**：同区同类标识唯一；导入按此 upsert——花名册随导入自动建档/刷新描述字段。
- 无种子：档案由首次导入真实文件建立（约 1100 块），也可手工增删（有读数的表删除 409 守卫）。

### meter_reading 月度读数
- `id、meter_id FK(删表由 409 挡,不级联)、ym CHAR(7)(YYYY-MM)、prev_total/curr_total、prev_sharp/peak/flat/valley、curr_sharp/peak/flat/valley(均 DECIMAL(14,2) NULL——水表只有 total,公共电表常只有 total)、factor_snap DECIMAL(10,2) NOT NULL(录入/导入时快照表倍率;之后改倍率不回溯历史,同 PV price_snap 口径)、note、source VARCHAR(12)(manual/import)、时间戳`
- **唯一键 (meter_id, ym)**：一表一月一条；重复导入幂等覆盖（先删后插）。
- **用量=派生不落库**：`(curr − prev) × factor_snap`（总与四段各自派生;缺读数=null）。后端 DTO 计算。
- **异常标记=前端派生**（meterLogic.ts 纯函数,spec 锁定）：漏抄(curr_total 空)、倒走(总用量<0)、时段不符(四段齐全时 |Σ段用量−总用量| 超容差 max(1, 总量1%))。只标不拦——真实数据就长这样,拦了导不进。

## 2. 接口（/api/meters,GET=viewer 可读、写=admin,SecurityConfig 统一门）
- 档案:GET /api/meters（可选 kind/zone 过滤）、POST、PUT /{id}、DELETE /{id}（有读数 409）
- 读数:GET /years（数据驱动年下拉）、GET /readings?ym=、POST /readings（同表同月 409）、PUT /readings/{id}、DELETE /readings/{id}
- 导入:POST /import——行自带 kind/zone/name/ym+档案描述字段+读数;表按 (kind,zone,name) 建档或刷新,读数按 (表,ym) 覆盖;kind/zone/ym 非法与 name 空=行级错误跳过,不整批拦。

## 3. 页面流（/meters,数据中心·业务流水组,账单管理之后）
- 顶部 Segmented 两段:**表档案 / 月度抄表**（会话内记住,KeepAlive）。两段共用:kind Segmented(电表/水表)+分区 tabs(全部/一期/二期/宿舍)。
- **月度抄表**（默认段）:年月选择（年数据驱动,同 PV 口径:有数据年∪当前年,初始=最新有数据年）;主表一行一表:标识|区域|企业|表类|倍率|上月行至|本月行至|本月用量|状态徽标(漏抄黄/倒走红/时段不符红);行点开抽屉=该表逐月历史,行式增删改(月份+读数+备注)。工具栏:导入/下载模板/导出当月。客户端分页(FPPager)。
- **表档案**:主表一行一表:标识|区域|位置|企业|表类|编号|倍率|读数条数;新增弹窗;行内改倍率/标识(重名 409);删除守卫。搜索框按标识/企业名过滤。
- viewer 全只读。

## 4. Excel 导入（parseWorkbook 整册多 sheet → sections 勾选段）
- 每 sheet 独立识别,**分区/类别与月份都从标题行取**（正则 (\d{4})年(\d{1,2})月 + 一期/二期/宿舍 + 电表/水表关键词;标题识别不出再按 sheet 名兜底）——真实水电费工作簿里同构 sheet 名月份各异,逐 sheet 自理;未识别 sheet 静默跳过（整册常混着上百张租户 sheet）。
- 表头定位:找含「区域」的行;列按名定位(区域/企业名称/表类/电表|水表名称/编码/倍率/上月行至/本月行至/备注),首列(A)=标识名;电表 TOU=表头行下一行 总/尖/峰/平/谷 子头,以上月行至/本月行至锚点偏移取 5 列;水表无子头单列。
- 行取数:标识列空=剔除(裁掉幽灵行);只读映射列(裁掉游离备注列);数字失败=null 不报错(缺读数是常态,进系统标「漏抄」而不是丢行)。
- 每识别 sheet → 一个 section:label=「一期园区电 · 2024年5月 · N 块表」,勾选后合并上传。
- 模板下载:6 sheet 骨架(标题行含当前年月+双行表头+示例行);导出当月:同构 6 sheet,可直接改后重导(修正回路,同 PV 导出口径)。

## 6. v2 结构化档案（2026-07-21 用户验收反馈,覆盖 §1/§3/§4 对应条目）

v1 档案是"原样字符串",用户裁定难懂:要与主数据关联、按 Excel 分类形式呈现。

### 6.1 数据模型增量（V46 迁移,ALTER meter）
- `tenant_id INT NULL`（FK 租户管理,不级联;户内表关联租户）
- `building_id INT NULL`（FK 楼栋管理;区域→楼栋映射,见 6.3）
- `ownership VARCHAR(8) NOT NULL DEFAULT 'share'`：`tenant`(租户表)/`share`(园区公摊)/`ops`(园区经营)/`infra`(配电总表)
- `tenant_name` 保留=Excel 企业名称原文（未匹配兜底+对账审计）;`spot`=方位（几楼几室/东西侧/高低区）。
- 回填方式：重导真实文件即回填（导入刷新档案字段）,V46 不写数据迁移。

### 6.2 租户名/方位拆分（前端纯函数 splitTenantSpot,spec 锁定;租户库=tenants api companyName 全量）
- 括号「X（Y）」(全半角括号均认)：两段先各自对租户库**全等**匹配→命中者为租户、另一段为方位（1-3楼（力灏）→租户力灏+方位1-3楼;邓宇峰（高区）→租户邓宇峰+方位高区）;都命中取 X;都不命中→按方位特征正则(见下)判方位段,余段为租户候选。
- 无括号连写「桑尼号西侧」：从尾部剥方位后缀(方位正则),剩余对租户库匹配。
- 方位正则：`(东|西|南|北)侧|高区|低区|门口|负?\d+[-—–]?\d*(楼|层|室|栋|座)|\d+[A-Za-z]?\d*室?$`
- 匹配优先级：全等 > 库名唯一包含候选(锂朋→锂朋) > 候选唯一包含库名;**多命中(邓宇峰×3)不自动挂**,tenant_id 置空保留原文,预览/档案标「待核」;人工在档案用 FPTenantPicker 指定。
- 公共表(6.3 判为 share/ops/infra)不做租户匹配,tenant_id 恒空。

### 6.3 归属自动分类 + 区域→楼栋映射（口径核实结论,依据 ELEC-COST-SPEC ops×5 与真实账单分摊列）
- 表类含 `总|变压器` 或名称含 `连接|馈` → `infra` 配电总表(层级节点,供损耗核算)
- 表类含 `户内` 或租户匹配成功 → `tenant`
- 公共表按关键词：`消防|电梯|楼道|照明|路灯|大堂|低压电房` → `share` 园区公摊(真实账单有 消防用电/电梯用电/路灯公摊 分摊列);`水泵|生活泵|绿化|办公|闸机|保安|门禁|招商|充电` → `ops` 园区经营(=电费成本模型运营性电表口径);其余公共默认 `share`,档案可改。
- 区域→楼栋(楼栋管理 8 栋,按 name 匹配 id,前端静态映射)：`A座→一期 A座;B|C|D|E|F|G座→一期 B-G座;宿舍|N栋→一期 宿舍区(zone=dorm 时);空地→一期 空地;[一二三四]车间|8-13栋→二期 一至四车间;[五六]车间→二期 五、六车间;三期|创业大厦|工业大厦→三期`;未命中→null 档案可改。

### 6.4 界面版式 v2
- **表档案列**：期数 | 楼栋(关联楼栋管理) | 方位 | 租户(FPTenantPicker 行内改,未匹配显原文+「待核」) | 归属徽标(租户/园区公摊/园区经营/配电总表) | 表名称 | 编码 | 倍率 | 读数条数。归属筛选 chips。
- **月度抄表列**：标识 | 租户/归属 | 倍率 | 上月 总·尖·峰·平·谷 | 本月 总·尖·峰·平·谷 | 本月用量 | 状态。电表直排全列(sticky 标识列+横向滚动,台账 FPLedgerTable 先例);水表仅 总 两列。
- **搜索**：匹配 租户名(含库内全名)+企业名称原文+方位——「力灏」「1-3楼」都能搜到 1-3楼（力灏）。
- 新增弹窗：kind/zone/期数楼栋(下拉自楼栋管理)/方位/租户(FPTenantPicker)/归属/表名/编码/倍率。
- 导入预览列改为拆分结果：期数|楼栋|方位|租户(或待核原文)|归属|倍率|上月总|本月总。模板文件保持真实版式不变(能直接吃原文件是核心价值)。

## 7. v3 分组版式（2026-07-21 用户验收反馈四条,覆盖 §3/§6.4 对应条目）

平铺分页用户裁定难用,改 Excel 式分组区块。分组纯函数 `groupMeterBlocks()`（src/utils/meterGroup.ts,meterGroup.spec.ts 锁定:区块归属/排序/汇总数值）。

### 7.1 分组与排序
- **区块 = area（车间/楼栋座）**;「连接X车间」馈线表随 X车间 区块（标识名或企业名称原文判定——真实馈线表如 三至二铝缆/area=铝缆 的「连接二车间」写在企业名称列）;area 空 → 未分区域。
- 期区序 p1→p2→dorm;区块序 = 区块内最小 sortNo（Excel 原序）。
- 区块内:**头行 = infra 配电总表**,随后 share/ops 公共表（Excel 原序）、tenant 户内表（方位楼层房号自然序:楼层[负X/中文/数字]→首个≥2位房号→原序兜底）。
- 全部 tab:期区→区块 两级标题;分区 tab 顶部 = 期区汇总条。

### 7.2 汇总口径（spec 锁定）
- **区块尾「X总用电量/总用水量」汇总行 = 区块内 ownership∈{tenant,share} 各表用量合计**,总/尖/峰/平/谷各列都汇（对齐本月行至列位,行首注「租户+公摊 用量合计」）;infra 不计（与分表重复）、ops 不计（园区经营,非向租户收费口径）;null 跳过,结果四舍五入 2 位防浮点尾差;区块无 tenant/share 表不出汇总行。
- 期区汇总条 = Σ区块。锚点（2024-05 二期一车间）:总表行 35170,tenant+share 合计 34476.23 ≈ Excel 34478.6（差=Excel 逐行四舍五入累计）。

### 7.3 交互与列
- **分页弃用**:两段均卡片内滚动;区块可折叠（点区块标题行,折叠保留 infra 头行+汇总行=Excel 组折叠保小计),默认全展开。
- **表名称列显 subName（电表①）**;标识名（name）是内部键不再示人（月度/档案两段同口径,新增弹窗仍录标识名),搜索仍可搜标识名;月度段 sticky 首列改 租户/方位（公共表显企业名称原文+归属徽标）。
- **「待核」徽标仅 ownership='tenant' 显**——公摊/经营/总表的企业名称原文只是描述,不是待匹配租户（导入预览 meterExcel 本就如此,档案段对齐）。
- 表档案段同样按区块分组呈现（区块小标题=区域）,列不变。

## 5. 边界与不做（YAGNI）
- 公摊分摊、损耗率、金额计算、租户档案 FK 匹配、缴费通知单——P-B/P-C。
- 模拟填充不做:有真实 Excel 全量数据,无需造数。
- 总表-分表勾稽(损耗对账)不做,数据齐后随 P-B 损耗刀一起。
- 与办公室水电(utilities/附表13)零共享零改动——彼为园区自身成本,此为向租户收费的原料。
