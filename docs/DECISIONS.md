# 产品拍板记录

只收**用户拍过板、现在仍然算数**的产品决定。被后来推翻的也留着，写明「已推翻，现行是…」，免得有人照旧做回去。

- 「出处」里的「记忆 xxx」是项目主人本机 Claude 记忆里的同名文件（不随仓走）；能对上的 PR、提交、代码位置一并写了。
- 日期是拍板那天。同一件事拍过几次的，写最后一次，前面的写进「现在」一格。
- 还没拍板的产品题不在这里，见 [../../README.md](../../README.md)。
- 新拍的板：加到对应领域的表里，写日期和出处；推翻旧的，就在旧那行写「已推翻」。
