(a)原则 · 11 条压成 6 张卡每张一句话 + 一个本仓例子;括号内是规范原文编号
1 · 频次先于一切(原则 1 / 11)
一天用 100 次的东西不动;几十次 ≤120;偶发 200;一屏一次 320。位移不修完不谈动效。
例:页签切换零动效(C1-04);PvQueue 行底色 120(C2-05);抽屉 200(C5-05);图表首绘 320(C6-02)
2 · 数据不为风格而动(原则 2 / 10)
只做同实体同键 200 形变,不同实体永不形变;不 count-up、不插值;不发明未记录的字面值。
例:换栋 b9/b10/b11 系列 id 带序号瞬换(C6-16);anaMotion.ts 镜像 320/200/120
3 · 只动不触发布局的属性(原则 3)
transform / opacity + color / fill / stroke / filter / clip-path;width、left、height 一律不动。
例:AnaBarRow width → clip-path inset(… round 4px)(C6-19);自绘导航条动 left → 删,换 FPLoadBar(C1-01)
4 · 入场用关键帧、退场瞬时、事后摘类(原则 4 / 8)
@keyframes … both 入场,v-if 退场;一生一次的类在 animationend 摘掉(.self 守卫,不用 .once);指示器过 200ms 门。
例:PvDayChart 数据组 fp-wipe 320 + .self(C6-17);useDeferredFlag(loading, 200)(C5-02)
5 · ECharts 逐系列注入、首绘/更新两条路径(原则 5 / 6)
getShallow 只在系列缺键时回落;首绘 320 + 错峰,更新 0 + 200;RO 只在尺寸真变时 resize。
例:motionize(opt, phase, env) 顶层 + 每个系列六个 animation* 键;AnaEChart.vue:132 RO 守卫(C6-02)
6 · 一次一个动的东西、reduced 是分工(原则 7 / 9)
登录后不接力、开抽屉只卡片 rise、按下只换一档底色;reduced 下 CSS 1ms、ECharts animation:false,转圈与 FPLoadBar 呼吸例外。
例:抽屉内三图瞬现(C5-05);FPLoadBar.vue:50-59 加 !important 救回呼吸(§2)
